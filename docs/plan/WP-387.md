# WP-387 — Wire pure WorkflowState line on MCP cancel

## Outcome

MCP workflow cancel logs pure `format_workflow_state_line` for the mapped
lifecycle state after a successful control cancel.

## Motivation

WP-356 published pure MCP workflow-state lines. Cancel already maps `TaskState`
to `WorkflowState` without a pure kind message on the observation path.

## Acceptance

1. Successful cancel maps to a view and logs pure workflow-state line + `state = as_str`.
2. `format_workflow_state_line` drops `#[allow(dead_code)]`.
3. Status/submit mapping remains unlogged on this pure line (avoid status poll noise).
4. Local gates and independent review pass.
