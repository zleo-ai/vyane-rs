# WP-283 — Pure NativePermissionSetError line + ceiling apply wire

## Outcome

CLI pure `format_native_permission_set_error_kind_line` prints
`NativePermissionSetError` kind tokens. Daemon native permission ceiling
application logs that kind when `restrict_by_all` fails.

## Motivation

WP-282 published tokens. Ceiling composition on the daemon submit path still
maps failures to `()` without a kind diagnostic.

## Acceptance

1. `format_native_permission_set_error_kind_line(e)` →
   `native permission: <as_str>` via `terminal_safe`.
2. `apply_native_permission_ceilings` logs `error = err.as_str()` on
   `restrict_by_all` failure (and on try_from failure when mappable).
3. Unit tests lock multi-word tokens; gates + independent review pass.
