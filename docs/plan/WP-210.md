# WP-210 — Pure serve loopback / start and config-error lines

## Outcome

Human `vyane serve` loopback rejection and start banner go through pure
`format_serve_loopback_only_line` / `format_serve_starting_line`. Generic
`format_config_error_line` is available for the shared config-error prefix
contract.

## Motivation

Serve control messages were ad-hoc string literals without pure unit coverage.

## Acceptance

1. Serve non-loopback reject and start banner use pure formatters.
2. Message shapes match the prior contract exactly.
3. Unit tests drive the shipped formatters (including generic config-error).
4. Local gates and independent review pass; no CI isolation train.
