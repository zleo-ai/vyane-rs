# WP-302 — Goal store error kind line + resident goal logs

## Outcome

CLI ships a pure `format_goal_store_error_kind_line`, and the resident goal
daemon logs store/pursuit failures with `GoalStoreError::as_str` kind tokens
instead of free-form Display payloads.

## Motivation

WP-301 published kind tokens. Resident goal acquisition, pursuer construction,
pursuit failure, and quarantine persist still logged `error = %error`, which
embeds goal ids and lease holders.

## Acceptance

1. `format_goal_store_error_kind_line` renders `goal store: <kind>` from domain tokens.
2. Unit tests lock the pure line for payload-bearing variants without embedding secrets.
3. Daemon goal paths log `error = …as_str()` (or downcast kind) for store-backed failures.
4. Local gates and independent review pass.
