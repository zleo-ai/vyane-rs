# WP-432 — Pure TaskOrigin/TaskKind on durable task status print

## Outcome

CLI logs pure `format_task_origin_line` and `format_task_kind_line` when
printing durable task status (human `task status` path).

## Motivation

WP-425 wires origin/kind on daemon workflow create freeze. The durable task
status human path still embeds origin via Display without pure kind logs
(WP-431 covered state only).

## Acceptance

1. Reuse pure origin/kind lines (`as_str` + `terminal_safe`).
2. `print_durable_task_status` logs both pure lines + `origin`/`kind` as_str.
3. Human multi-line durable status body shape unchanged.
4. Existing origin/kind unit asserts remain green.
5. Local gates and independent review pass.
