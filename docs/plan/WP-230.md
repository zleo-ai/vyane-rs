# WP-230 — Public GoalStatus as_str for domain token access

## Outcome

`GoalStatus::as_str` is public (not `pub(crate)`), matching other goal domain
enums so human/CLI surfaces can use domain tokens without crate-internal access.

## Motivation

WP-228/229 published public `as_str` for continuity/pursuit/criterion tokens.
`GoalStatus` already had `Display` and crate-private `as_str`; public access
aligns the API surface.

## Acceptance

1. `GoalStatus::as_str` is public.
2. Unit test locks shipped tokens.
3. Local gates and independent review pass; no CI isolation train.
