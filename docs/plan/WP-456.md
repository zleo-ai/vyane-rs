# WP-456 — Pure TakeoverRunStatus on continuity-execute approval evidence

## Outcome

CLI `goal continuity-execute` logs pure `format_takeover_run_status_line` when
approval evidence assembled into the execute prompt carries a closed
`TakeoverRunStatus`.

## Motivation

WP-453 covers queue-time upstream run status. Continuity-execute prompt assembly
already copies predecessor `run_status` via `append_approval_evidence` without
pure-logging that closed kind.

## Acceptance

1. Reuse pure `format_takeover_run_status_line` (no new private table).
2. `append_approval_evidence` logs pure line + `status = as_str` when run status
   is present.
3. Absent run status emits no extra pure log.
4. Prompt text body shape unchanged.
5. Local gates and independent review pass.
