# WP-391 — Wire pure DeliveryStatus on A2A message projection

## Outcome

Local A2A `message_view` logs pure `format_delivery_status_line` and stores the
delivery status field via `as_str` (not free-form Display).

## Motivation

WP-354 published pure delivery-status lines. A2A projections still used
`to_string()` without a pure kind diagnostic on the projection path.

## Acceptance

1. `message_view` logs pure delivery-status line + structured `status = as_str`.
2. `MessageView.delivery_status` is filled from `status.as_str()`.
3. `format_delivery_status_line` drops `#[allow(dead_code)]`.
4. Local gates and independent review pass.
