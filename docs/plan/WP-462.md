# WP-462 — Pure ToolInvocationStatus on native tool-lane TimedOut settle

## Outcome

Native AgentRun settle pure-logs `format_tool_invocation_status_line` for
`ToolInvocationStatus::TimedOut` when the turn stop is
`NativeTurnStop::TimedOut` (tool-lane timeout).

## Motivation

WP-268 pure-logs the stop kind; WP-460 pure-logs tool status on ask settle.
Tool-lane timeouts map to `NativeTurnStop::TimedOut` (distinct from outer
wall-clock `ErrorKind::Timeout` settle). The closed tool-status token was not
pure-logged on that host.

## Acceptance

1. Reuse pure `format_tool_invocation_status_line` for TimedOut.
2. On `NativeTurnStop::TimedOut` quiesced settle, pure-log tool status +
   `status = as_str`.
3. Existing pure stop-kind log remains; outer wall-clock Timeout path unchanged.
4. Unit tests keep locking the `timed_out` tool-status token.
5. Settlement failure codes and behavior unchanged.
6. Local gates and independent review pass.
