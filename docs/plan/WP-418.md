# WP-418 — Pure WebSearchContextSize on native web-search register

## Outcome

CLI ships pure `format_web_search_context_size_line` and logs it when a native
AgentRun registers hosted web search with an explicit search context size.

## Motivation

`WebSearchContextSize` already has kind tokens (WP-262). The native register
path freezes that closed size without a pure kind diagnostic.

## Acceptance

1. Pure `format_web_search_context_size_line` uses `size.as_str()` + terminal_safe.
2. Before successful web-search tool registration, log pure line + `context = as_str`.
3. Unit test locks low/medium/high tokens.
4. Registration and policy payloads unchanged.
5. Local gates and independent review pass.
