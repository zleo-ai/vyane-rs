# WP-301 — GoalStoreError kind tokens

## Outcome

`GoalStoreError` publishes snake_case kind-only `as_str` tokens so resident
goal / daemon logs can report store failures without ids, holders, or payloads.

## Motivation

`AgentStoreError` already has kind tokens (WP-298). Resident goal acquisition
and quarantine paths still log `error = %error` Display strings that carry
goal ids and lease holders. A public kind surface is the prerequisite for
kind-only tracing and pure CLI lines.

## Acceptance

1. Every `GoalStoreError` variant has a stable snake_case kind token via `as_str`.
2. Tokens never embed ids, holders, operations, remaining counts, or IO/JSON payloads.
3. Unit tests lock representative variants including payload-bearing ones.
4. Local gates and independent review pass.
