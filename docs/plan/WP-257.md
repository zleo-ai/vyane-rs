# WP-257 — Domain tokens for kernel capability closed enums

## Outcome

`FilesystemCapability`, `IsolationStrength`, and `CapabilityRejectionReason`
expose public `as_str` / `Display` (reason Display already exists; route it
through `as_str`).

## Motivation

Capability admission evidence is already serde snake_case. Domain tokens make
audit/human surfaces share the same closed rejection and capability vocabulary.

## Acceptance

1. All three enums have `as_str`; Display single-sources `as_str`.
2. Unit tests lock multi-word tokens (`caller_workdir_editing`,
   `adapter_delegated`, `workdir_canonicalization_failed`).
3. Local gates and independent review pass; no CI isolation train.
