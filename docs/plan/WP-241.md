# WP-241 — Public as_str for vyane-task string enums

## Outcome

The `impl_string_enum!` macro in `vyane-task` publishes `as_str` as `pub`
(not `pub(crate)`), so `TaskState` and sibling string enums match the domain
token train used by goal/workflow/core.

## Motivation

CLI human formatters already call `TaskState` Display; public `as_str` enables
the same access pattern as `RunStatus` / `GoalStatus` without crate-internal
visibility.

## Acceptance

1. Macro emits `pub const fn as_str`.
2. Unit test locks representative `TaskState` tokens.
3. Local gates and independent review pass; no CI isolation train.
