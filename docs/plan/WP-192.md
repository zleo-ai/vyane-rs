# WP-192 — CLI human continuity-signal line pure formatter + tests

## Outcome

Human `vyane goal continuity-signal` projects the signal write result through
pure `format_continuity_signal_line`: terminal-safe goal id, `recorded`|
`unchanged`, and terminal-safe `next_ready_step`.

## Motivation

After WP-189/191 hardened continuity next-action and approval human paths, the
signal ingress human path still used ad-hoc `println!` without a pure helper or
terminal safety on free text.

## Acceptance

1. Human continuity-signal path uses `format_continuity_signal_line` (JSON
   unchanged).
2. Tab line: safe goal_id, `recorded` or `unchanged`, safe next_ready_step.
3. Unit tests drive the shipped formatter for both changed and unchanged cases
   (including control-char escape).
4. Local gates and independent review pass; no CI isolation train.
