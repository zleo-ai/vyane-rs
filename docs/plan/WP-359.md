# WP-359 — Pure goal observation signal/status/watch lines

## Outcome

CLI ships pure kind-only human lines for `GoalObservationSignalKind`,
`GoalObservationStatus`, `GoalObservationWatchStatus`, and
`GoalObservationWatcherErrorCode`.

## Motivation

These observation ingress/watch enums already publish snake_case `as_str`
tokens used on service observation paths, but lacked pure CLI formatters. After
WP-358 this was the remaining surveyed half-landed pure-line gap for goal
observation diagnostics.

## Acceptance

1. Pure `format_goal_observation_signal_kind_line` uses only domain `as_str`.
2. Pure `format_goal_observation_status_line` uses only domain `as_str`.
3. Pure `format_goal_observation_watch_status_line` uses only domain `as_str`.
4. Pure `format_goal_observation_watcher_error_code_line` uses only domain `as_str`.
5. Unit tests lock one non-trivial token per formatter.
6. Local gates and independent review pass.
