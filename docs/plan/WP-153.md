# WP-153 — isolate detach fast-return success fixture in CI

## Outcome

Run `detach_returns_fast_then_completes_success` in a fresh CI process for
normal and coverage jobs.

Production detach submission behavior does not change.

## Motivation

This multi_thread Wiremock detach fixture returns from the parent CLI while a
worker continues against a delayed target. Neighboring multi_thread control-plane
fixtures already required process isolation under suite/GHA load.

Note: the package number follows WP-152 (bounded workflow output projection on
main); an earlier draft of this isolation briefly collided with that number.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
