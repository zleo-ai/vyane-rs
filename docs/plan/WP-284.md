# WP-284 — InProcess authority/completion/native-bind error kind tokens

## Outcome

`InProcessAuthorityError`, `InProcessCompletionError`,
`InProcessCompletionStageError`, and `InProcessNativeBindError` publish
snake_case `as_str` tokens with unit tests locking multi-word kinds.

## Motivation

In-process native execution authority is a core P1 seam. Failures are already
closed enums with Display prose only; kind tokens enable diagnostics without
payloads.

## Acceptance

1. Each of the four enums has exhaustive `as_str` covering all variants.
2. Unit tests lock multi-word tokens (e.g. `validation_task_failed`,
   `unsupported_scope`, `validation_unavailable`).
3. Local gates and independent review pass.
