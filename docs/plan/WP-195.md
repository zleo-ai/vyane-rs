# WP-195 — CLI human verify result pure formatter + tests

## Outcome

Human `vyane goal verify` projects `AcceptanceVerification` through pure
`format_verify_result`: success|inconclusive from `all_satisfied`, terminal-safe
goal id and summary.

## Motivation

Verify human mode only printed a terminal-safe summary, omitting the durable
success/inconclusive result token that matches the command exit contract.

## Acceptance

1. Human verify path uses `format_verify_result` (JSON unchanged).
2. Prints `result` (`success` when all_satisfied else `inconclusive`), safe
   goal id, safe summary.
3. Unit tests drive the shipped formatter with real `AcceptanceVerification`
   values (both result tokens + escape).
4. Local gates and independent review pass; no CI isolation train.
