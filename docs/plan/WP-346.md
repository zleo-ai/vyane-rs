# WP-346 — NativeSessionTransition kind tokens + pure line

## Outcome

`NativeSessionTransition` publishes snake_case kind-only `as_str` tokens, and
CLI ships pure `format_native_session_transition_line`.

## Motivation

Native session transitions carried revision, update, and binding payloads with
no closed top-level kind surface for diagnostics. After WP-345 this was the
remaining surveyed session-transition enum without `as_str`.

## Acceptance

1. Every `NativeSessionTransition` variant has a stable snake_case kind via `as_str`.
2. Tokens never embed revisions, session ids, updates, or bindings.
3. Unit tests lock all three kinds with secret fixtures.
4. Pure `format_native_session_transition_line` is unit-tested.
5. Local gates and independent review pass.
