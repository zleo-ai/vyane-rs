# WP-146 — isolate MCP workflow resident-daemon fixture in CI

## Outcome

Run `mcp_workflow_tools_use_the_authenticated_resident_daemon` in a fresh CI
process for normal and coverage jobs.

Production MCP workflow tool authentication and resident-daemon behavior does
not change.

## Motivation

This multi-thread MCP workflow fixture starts a resident daemon, holds a
Wiremock target, and drives stdio MCP tools against authenticated loopback
control. Neighboring multi-thread daemon workflow fixtures already required
process isolation under suite/GHA load.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
