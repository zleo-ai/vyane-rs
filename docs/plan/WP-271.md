# WP-271 — LifecycleObservation tokens on Process AgentRun diagnostics

## Outcome

Process AgentRun host logs emit closed `LifecycleObservation` snake_case
tokens instead of Debug `?state`.

## Motivation

Dispatch/completion warn paths still format lifecycle evidence with Debug
(`?state`), which is not the operator vocabulary and can include unstable
struct shapes. A stable token keeps daemon logs parseable and aligned with
the rest of the AgentRun token train.

## Acceptance

1. `LifecycleObservation` publishes `as_str()` for
   `never_started` / `running` / `stopped` / `uncertain`.
2. Process AgentRun warn logs use `lifecycle = state.as_str()` (not `?state`).
3. Unit test locks multi-word `never_started` and `stopped` tokens.
4. Local gates and independent review pass; no CI isolation train.
