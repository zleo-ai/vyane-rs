# WP-318 — Kernel ledger/session post-run log kinds

## Outcome

Kernel best-effort ledger append and session update warnings after a completed
run log `ErrorKind::as_str` tokens instead of free-form `VyaneError` Display.

## Motivation

WP-316 closed `error = %error` sites. Kernel dispatch still used `error = %e`
on post-success ledger/session paths, which embeds full error messages.

## Acceptance

1. Non-streaming ledger append failure logs `error = e.kind.as_str()`.
2. Session store update failure logs `error = e.kind.as_str()`.
3. Streaming ledger append failure logs `error = e.kind.as_str()`.
4. Local gates and independent review pass.
