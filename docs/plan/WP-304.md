# WP-304 — TaskStoreError kind tokens

## Outcome

`TaskStoreError` publishes snake_case kind-only `as_str` tokens so daemon /
REST task paths can report store failures without task ids or lease owners.

## Motivation

Agent, goal, and message stores already have kind tokens (WP-298, WP-301,
WP-303). The durable task store is the remaining owner-scoped SQLite surface
without a kind API.

## Acceptance

1. Every `TaskStoreError` variant has a stable snake_case kind token via `as_str`.
2. Tokens never embed task ids, owners, revisions, or IO/SQLite payloads.
3. Unit tests lock representative variants including payload-bearing ones.
4. Local gates and independent review pass.
