# WP-421 — Pure FailureCode on daemon workflow settle/interrupt

## Outcome

CLI ships pure `format_task_failure_code_line` and logs it when a daemon
workflow worker finishes with a `TaskSettlement::Failed` code or an interrupt
`FailureCode`.

## Motivation

`vyane_task::FailureCode` already has kind tokens via `impl_string_enum!`.
Daemon workflow settle/interrupt paths persist the code but only log settlement
kind tokens, not the closed failure-code diagnostic.

## Acceptance

1. Pure `format_task_failure_code_line` uses `code.as_str()` + `terminal_safe`.
2. When finishing a worker with `TaskSettlement::Failed { code, .. }`, log pure
   line + `failure_code = as_str`.
3. When finishing with `CompletionAction::Interrupt(code)`, log pure line +
   `failure_code = as_str`.
4. When lease-loss forces a Failed settlement, log the pure failure code.
5. Unit tests lock representative snake_case tokens; settlement mapping
   unchanged; local gates and independent review pass.
