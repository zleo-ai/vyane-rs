# WP-349 — RunAttemptOutcomeView kind tokens + pure line

## Outcome

Public `RunAttemptOutcomeView` publishes snake_case kind-only `as_str` tokens
(`ok` / `err`), and CLI ships pure `format_run_attempt_outcome_view_line`.

## Motivation

Allowlisted run-attempt views carried error kind, static message, and failover
flags with no closed top-level kind surface. After WP-348 this was the remaining
surveyed public attempt-outcome view without `as_str`.

## Acceptance

1. Every `RunAttemptOutcomeView` variant has a stable snake_case kind via `as_str`.
2. Tokens never embed error kinds, messages, or `failed_over`.
3. Unit tests lock both kinds with a secret message fixture.
4. Pure `format_run_attempt_outcome_view_line` is unit-tested.
5. Local gates and independent review pass.
