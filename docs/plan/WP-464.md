# WP-464 — Pure ErrorKind on native AbortedAfterToolActivity settle

## Outcome

Native AgentRun settle pure-logs `format_error_kind_line_token` for the nested
`ErrorKind` when the turn stop is `NativeTurnStop::AbortedAfterToolActivity`.

## Motivation

WP-268 pure-logs the stop kind token (`aborted_after_tool_activity`). That stop
carries a nested model/transport `ErrorKind` that is already materialised on
the settle host, but only the stop kind was pure-logged — the nested closed
error token was dropped. WP-461/378 already pure-log `ErrorKind` on the
`Ok(Err(error))` and outer-timeout paths; this residual aligns the abort-after-
tool stop path with the same helper.

## Acceptance

1. Reuse pure `format_error_kind_line_token` (no new formatter).
2. On `NativeTurnStop::AbortedAfterToolActivity { kind }` quiesced settle,
   pure-log error kind + `error = as_str` after the existing stop pure log.
3. Existing pure stop-kind log and settlement failure codes unchanged.
4. Unit tests keep locking closed `error kind:` tokens.
5. Local gates and independent review pass.
