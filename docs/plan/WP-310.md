# WP-310 — WorkflowControlError kind tokens

## Outcome

`WorkflowControlError` publishes snake_case kind-only `as_str` tokens for the
MCP/daemon workflow control adapter surface.

## Motivation

The closed unit enum already has human Display strings, but no stable kind API
for logs and pure CLI lines. Other workflow status enums already expose tokens.

## Acceptance

1. Every `WorkflowControlError` variant has a stable snake_case kind via `as_str`.
2. Unit tests lock all six kinds.
3. Local gates and independent review pass.
