# WP-239 — CLI GoalStatusArg Display uses domain GoalStatus tokens

## Outcome

`GoalStatusArg` implements `Display` via domain `GoalStatus::as_str`.

## Motivation

WP-230 made `GoalStatus::as_str` public. CLI clap `GoalStatusArg` still lacked
Display for consistent snake_case tokens (including `in_progress`).

## Acceptance

1. `Display for GoalStatusArg` uses `GoalStatus::from(*self).as_str()`.
2. Unit test locks tokens against domain (especially `in_progress`).
3. Local gates and independent review pass; no CI isolation train.
