# WP-320 — Pure workflow submit/control client error lines

## Outcome

CLI ships pure `format_workflow_submit_error_kind_line` and
`format_daemon_workflow_control_error_kind_line` over WP-319 domain tokens.

## Motivation

WP-319 published client error kinds. Operator pure lines still lacked formatters
for submit and control-client failures.

## Acceptance

1. Pure lines render `workflow submit: <kind>` and `workflow control client: <kind>`.
2. Unit tests lock representative kinds without embedding run ids.
3. Local gates and independent review pass.
