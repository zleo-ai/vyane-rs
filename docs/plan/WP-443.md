# WP-443 — Pure Protocol on legacy session list print

## Outcome

CLI logs pure `format_protocol_line` when printing a legacy session list line.

## Motivation

`Protocol` pure lines are wired on check and native freeze. Legacy session list
embeds target Display without a pure protocol kind diagnostic.

## Acceptance

1. Reuse pure `format_protocol_line` (`as_str` + `terminal_safe`).
2. `print_legacy_session_line` logs pure protocol + `protocol = as_str`.
3. Human one-line legacy session shape unchanged.
4. Existing Protocol unit asserts remain green.
5. Local gates and independent review pass.
