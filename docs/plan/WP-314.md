# WP-314 — Kind-only resident supervisor failure logs

## Outcome

Resident goal supervisor failures and shutdown-handler install failures log
closed kind tokens instead of free-form `error = %error` Display strings.

## Motivation

WP-302 cleaned goal-store paths inside the supervisor loop. Outer daemon
wrapping still logged full anyhow Display when the supervisor task exited with
an error, and signal-handler install used free-form IO Display.

## Acceptance

1. Resident goal supervisor failure logs `error = GoalStoreError::as_str()` when
   the source is a store error, else `internal`.
2. Shutdown-handler install failure logs a fixed `install_failed` kind.
3. Local gates and independent review pass.
