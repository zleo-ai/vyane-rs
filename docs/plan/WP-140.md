# WP-140 — isolate configured tool-ask native AgentRun fixture in CI

## Outcome

Run `configured_tool_ask_stops_the_resident_lane_before_the_write_or_replay`
in a fresh CI process for normal and coverage jobs.

Production tool-ask / policy_denied resident-lane behavior does not change.

## Motivation

This multi-thread native AgentRun fixture drives Wiremock tool_calls, resident
daemon submission, and terminal polling until `policy_denied`. Neighboring
multi-thread native AgentRun fixtures already required process isolation under
suite/GHA load.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
