# WP-383 — Pure workflow run status + task settlement on worker finish

## Outcome

Daemon workflow worker finish on successful engine outcomes logs pure
`format_workflow_run_status_line` and `format_task_settlement_line`.

## Motivation

WP-353/344 published pure status/settlement lines. Worker finish already mapped
`WorkflowRunStatus` to `TaskSettlement` without pure kind messages.

## Acceptance

1. `Ok(Ok(outcome))` finish logs pure workflow-run status line + pure task settlement line.
2. Structured `status` and `settlement` fields remain kind-only via `as_str`.
3. Both pure formatters drop `#[allow(dead_code)]`.
4. Local gates and independent review pass.
