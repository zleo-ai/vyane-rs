# WP-238 — CLI RunStatusArg Display uses domain RunStatus tokens

## Outcome

`RunStatusArg` implements `Display` via domain `RunStatus::as_str`.

## Motivation

WP-236/237 routed run status and sandbox labels through domain tokens. CLI clap
`RunStatusArg` still lacked Display for help/diagnostics consistency.

## Acceptance

1. `Display for RunStatusArg` uses `RunStatus::from(*self).as_str()`.
2. Unit test locks tokens against domain.
3. Local gates and independent review pass; no CI isolation train.
