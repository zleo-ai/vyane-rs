# WP-368 — Pure + wire NativeFilesystemPolicyError on native AgentRun

## Outcome

CLI ships pure `format_native_filesystem_policy_error_kind_line` and wires it
onto native AgentRun workspace tool registry assembly failures.

## Motivation

`NativeFilesystemPolicyError` already publishes kind tokens. Fresh-native
AgentRun still swallowed `workspace_tool_registry_with_policy` failures as
silent `Unknown` outcomes.

## Acceptance

1. Pure line renders `native filesystem policy: <as_str>` for invalid_read_policy / invalid_write_policy / registry.
2. Native AgentRun logs pure line + structured `error = as_str` on registry assembly Err.
3. No path-pattern / exclude payloads in logs.
4. Unit tests lock tokens; local gates and independent review pass.
