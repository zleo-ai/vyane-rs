# WP-357 — Pure message-event / run-status / continuity-mode lines

## Outcome

CLI ships pure kind-only human lines for `MessageEventKind`, `RunStatus`, and
`GoalContinuityMode`.

## Motivation

These closed status/mode enums already publish snake_case `as_str` tokens, but
lacked pure CLI formatters. After WP-356 this was the remaining surveyed
half-landed pure-line gap for message events, ledger run status, and continuity
mode.

## Acceptance

1. Pure `format_message_event_kind_line` uses only `MessageEventKind::as_str`.
2. Pure `format_run_status_line` uses only `RunStatus::as_str`.
3. Pure `format_goal_continuity_mode_line` uses only `GoalContinuityMode::as_str`.
4. Unit tests lock one non-trivial token per formatter.
5. Local gates and independent review pass.
