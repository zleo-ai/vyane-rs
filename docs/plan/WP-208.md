# WP-208 — Pure workflow error human prefix line

## Outcome

Human workflow engine failures print through pure `format_workflow_error_line`
(`config error:` vs `error:` based on `is_validation_or_config`).

## Motivation

Workflow error stderr still branched on validation with ad-hoc `eprintln!`; pure
helper unit-tests the operator prefix contract.

## Acceptance

1. `print_workflow_error` uses `format_workflow_error_line`.
2. Validation/config → `config error: {msg}`; other → `error: {msg}`.
3. Unit tests drive the shipped helper for both branches.
4. Local gates and independent review pass; no CI isolation train.
