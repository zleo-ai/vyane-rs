# WP-463 — Pure ToolInvocationStatus on native cancel Unknown settle

## Outcome

Native AgentRun cancel Unknown settle pure-logs
`format_tool_invocation_status_line` for `ToolInvocationStatus::Cancelled`
when the turn stop is `NativeTurnStop::Cancelled`.

## Motivation

WP-461 pure-logs the stop kind on the cancel Unknown path. Tool-lane cancel
maps to the same stop; the closed tool-status token was not pure-logged
alongside (ask/timeout already have companion tool-status pure logs).

## Acceptance

1. Reuse pure `format_tool_invocation_status_line` for Cancelled.
2. On `NativeTurnStop::Cancelled` Unknown path, pure-log tool status +
   `status = as_str` after stop pure log.
3. Still return Unknown (no false failure settlement).
4. Unit tests lock the `cancelled` tool-status token.
5. Settlement behavior unchanged.
6. Local gates and independent review pass.
