# WP-207 — Pure cancel / timeout / panic / unavailable tool outputs

## Outcome

Native tool execution terminal messages for cancel, timeout, panic, unavailable
registration, and tool failure Display go through pure helpers used on every
execute path (ordinary + authorized).

## Motivation

WP-205/206 purified prepare-path policy stop messages; execute-path cancel /
timeout / panic / unavailable strings were still duplicated inline.

## Acceptance

1. All cancelled/timed-out/panicked/unavailable/failed model outputs use pure
   helpers (`tool_execution_cancelled_output`, `tool_execution_timed_out_output`,
   `tool_panicked_output`, `tool_unavailable_output`, `tool_failed_output`).
2. `terminal_outcome` returns those static cancelled/timeout strings.
3. Unit tests drive the shipped helpers.
4. Local gates and independent review pass; no CI isolation train.
