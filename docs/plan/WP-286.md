# WP-286 — OwnerContextError kind tokens

## Outcome

`OwnerContextError` publishes snake_case `as_str` tokens for principal-to-owner
binding failures; unit tests lock multi-word kinds.

## Motivation

Owner resolution (WP-49) is foundational P1/P2 auth. Failures already use a
closed enum with Display prose only; kind tokens support diagnostics without
principal values.

## Acceptance

1. `OwnerContextError::as_str` covers all five variants.
2. Unit test locks multi-word tokens (`authentication_failed`,
   `invalid_principal`, `resolution_failed`, `reserved_owner`).
3. Local gates and independent review pass.
