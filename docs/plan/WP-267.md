# WP-267 — Wire tool status pure line on stream ToolUse path

## Outcome

CLI stream `ToolUse` events print `format_tool_invocation_status_line` with
`ToolInvocationStatus::Executed` after the existing `[tool]` progress line,
removing the WP-266 `dead_code` half-land.

## Motivation

WP-266 landed a pure formatter without a shipped call site. The dispatch stream
already emits `ToolUse` for progress; pairing it with the closed status token
puts the native vocabulary on stderr operators already watch.

## Acceptance

1. Non-json stream path eprints `format_tool_invocation_status_line(Executed)`
   after the tool-use line.
2. `format_tool_invocation_status_line` has no `allow(dead_code)`.
3. Unit tests for the pure formatter remain green; gates pass.
4. Independent review APPROVE; no CI isolation train.
