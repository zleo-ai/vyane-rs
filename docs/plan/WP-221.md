# WP-221 — Pure stream notice and tool-use lines

## Outcome

Interactive dispatch stream operator notices (unsupported stream fallback,
--stream applicability) and tool-use progress lines go through pure formatters.

## Motivation

After cancel/worker diagnostic purification, remaining interactive stream
operator feedback still uses ad-hoc `eprintln!` interpolations.

## Acceptance

1. Stream-unsupported fallback notice uses a pure formatter (terminal-safe
   target display).
2. Stream-not-applicable notice uses a pure formatter.
3. Tool-use progress line (`[tool] name: summary`) uses a pure formatter with
   terminal-safe free text.
4. Unit tests drive the shipped formatters.
5. Local gates and independent review pass; no CI isolation train.
