# WP-97 — serialize broker supervisor fixtures in standard CI

## 目标

消除 macOS 与本地普通全仓测试中 `vyane-broker` supervisor fixtures 的
paused-time 交叉饥饿，使标准 test job 与已经稳定的 coverage 调度一致。

本包不跳过测试，也不改变 broker 生产行为。

## 决策模型

- workspace 普通测试批次排除 `vyane-broker`，其他未列出的包继续默认并发。
- `vyane-broker` 单独以 `--test-threads=1` 运行；每个测试内部的 Tokio
  并发保持不变。
- 已有 `vyane-service` 与 `vyane-cli` 串行批次保持不变。
- test job 的 20 分钟总上限保持不变。

## 验收门

1. broker 全包测试在单线程调度下通过。
2. CI 没有遗漏任何 workspace、broker、service 或 CLI 测试。
3. format、Clippy、全仓测试与 parity 通过。
4. 独立评审与云端 Ubuntu、macOS、coverage、MSRV、release gate 全绿。
