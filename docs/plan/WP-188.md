# WP-188 — CLI human goal line pure formatter + tests

## Outcome

Human `vyane goal list/get/...` one-line projection goes through pure
`format_goal_line` used by `print_goal_line`. Unit tests drive the shipped
formatter with real `GoalRecord` values (status Display, priority, terminal-safe
id/title).

## Motivation

After WP-179–187 locked `output.rs` human surfaces, goal CLI human lines still
wrote only through `writeln!` without a pure helper.

## Acceptance

1. `print_goal_line` wraps `format_goal_line` (write + flush unchanged).
2. Line is tab-separated: safe id, status snake_case, priority, safe title.
3. Control characters in id/title are escaped via `terminal_safe`.
4. Unit tests call the shipped formatter with real `GoalRecord`.
5. Local gates and independent review pass; no CI isolation train.
