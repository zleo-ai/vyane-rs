# WP-157 — isolate detached no-frontier failover fixture in CI

## Outcome

Run `detached_no_frontier_replays_parent_failover_filter` in a fresh CI process
for normal and coverage jobs.

Production detached no-frontier failover filter behavior does not change.

## Motivation

This multi_thread detach fixture replays the parent failover filter without a
frontier. Neighboring multi_thread detach fixtures already required process
isolation under suite/GHA load.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
