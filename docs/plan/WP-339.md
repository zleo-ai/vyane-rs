# WP-339 — Kind-only broker adapter result logs

## Outcome

Broker pump delivery logs closed `AdapterOutcome` and `AdapterFailure` kind
tokens when an adapter returns, without bodies, receipts, reason codes, or
delays.

## Motivation

WP-338 published adapter result kinds. The pump still had no structured
operator signal distinguishing local_handled / reply / transport_delivered from
retry / permanent / uncertain failures.

## Acceptance

1. On adapter `Ok(outcome)`, log `outcome` as a kind token only before settle.
2. On adapter `Err(failure)`, log `failure` as a kind token only before nack/uncertain handling.
3. Never log bodies, receipts, reason codes, or delays in those structured logs.
4. Local gates and independent review pass.
