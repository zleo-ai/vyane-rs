# WP-433 — Pure FailureCode on durable task status print

## Outcome

CLI logs pure `format_task_failure_code_line` when printing durable task status
that carries an explicit closed `FailureCode`.

## Motivation

WP-421 wires failure codes on daemon workflow settle/interrupt. Durable task
status embeds failure via Display without a pure kind log when present
(WP-431/432 covered state/origin/kind).

## Acceptance

1. Reuse pure `format_task_failure_code_line` (`as_str` + `terminal_safe`).
2. When `task.failure_code` is `Some(code)`, log pure line +
   `failure_code = as_str` from `print_durable_task_status`.
3. When failure_code is absent, do not invent a failure log line.
4. Human multi-line durable status body shape unchanged.
5. Local gates and independent review pass.
