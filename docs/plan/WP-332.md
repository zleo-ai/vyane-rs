# WP-332 — Wire workflow submit/control client error kinds

## Outcome

MCP workflow control mapping logs `WorkflowSubmitError` and
`DaemonWorkflowControlError` kinds when translating client failures into
`WorkflowControlError`.

## Motivation

WP-319/WP-320 published and pure-formatted these kinds. Mapping still had no
structured kind-only signal, leaving `as_str` half-landed with dead_code allows.

## Acceptance

1. `map_submit_error` logs `error = error.as_str()` before mapping.
2. `map_control_error` logs `error = error.as_str()` before mapping.
3. Remove dead_code allows on both client `as_str` methods.
4. Local gates and independent review pass.
