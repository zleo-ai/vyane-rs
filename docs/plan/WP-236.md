# WP-236 — Domain RunStatus and Sandbox tokens + CLI wire

## Outcome

`RunStatus` and `Sandbox` expose public `as_str` / `Display`. CLI
`status_name` and `sandbox_name` use domain tokens only.

## Motivation

Human run tables and permission-check sandbox labels still map statuses through
CLI private match tables. Domain ownership matches the WP-232/235 token train.

## Acceptance

1. `RunStatus` has public `as_str` + `Display` (snake_case, matching serde).
2. `Sandbox` has public `as_str` + `Display` (kebab-case, matching serde).
3. CLI `status_name` / `sandbox_name` return domain `as_str` only.
4. Unit tests lock domain tokens; existing CLI human tests still pass.
5. Local gates and independent review pass; no CI isolation train.
