# WP-378 — Wire pure ErrorKind line on native turn failures

## Outcome

Native AgentRun maps driver errors and outer wall-clock timeouts with pure
`format_error_kind_line_token` before quiesced failure settlement.

## Motivation

WP-322 published pure `ErrorKind` lines. Native turn failure still mapped
`error.kind` to `RunFailureCode` without a pure kind diagnostic message.

## Acceptance

1. Driver `Ok(Err)` (non-cancelled) logs pure error-kind line + structured `error = kind.as_str`.
2. Outer `timeout_at` Err logs pure `timeout` kind line before timed-out settlement.
3. Cancelled remains silent Unknown (no false failure kind).
4. `format_error_kind_line_token` drops `#[allow(dead_code)]`.
5. Local gates and independent review pass.
