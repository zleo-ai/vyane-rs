# WP-274 — Recovery/completion item status tokens + degraded logs

## Outcome

`AgentRecoveryItemStatus` and `AgentCompletionProjectionStatus` publish
snake_case `as_str` tokens. Supervisor recovery and completion cycles log
`first_degraded` when degraded items drive backoff (parallel to WP-273
execution).

## Motivation

WP-273 wired execution degraded kinds. Recovery and completion paths still
only count degraded items without exposing which closed status caused
backoff.

## Acceptance

1. `AgentRecoveryItemStatus::as_str` covers all variants (kind-only).
2. `AgentCompletionProjectionStatus::as_str` covers all variants (kind-only).
3. Recovery and completion supervisor degraded branches log
   `first_degraded = <as_str>` (and `degraded` count).
4. Unit tests lock multi-word tokens; gates + independent review pass.
