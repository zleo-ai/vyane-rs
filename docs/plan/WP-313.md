# WP-313 — Register web tool pure kind lines

## Outcome

CLI ships pure `format_register_web_fetch_tool_error_kind_line` and
`format_register_web_search_tool_error_kind_line` over domain kind tokens.

## Motivation

WP-300 published registration kind tokens. Operator/CLI pure surfaces still
lacked formatters for hosted web tool registration failures.

## Acceptance

1. Pure lines render `register web_fetch: <kind>` and `register web_search: <kind>`.
2. Unit tests lock policy and registry kinds.
3. Local gates and independent review pass.
