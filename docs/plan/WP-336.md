# WP-336 — CancelOutcome kind tokens + pure line

## Outcome

`CancelOutcome` publishes snake_case kind-only `as_str` / `Display` tokens, and
CLI ships pure `format_cancel_outcome_line`.

## Motivation

Agent cancel settlement outcomes (`Cancelled` / `ControllerUnavailable`) had no
closed kind surface for diagnostics. After WP-335 this was the remaining
surveyed cancel-status enum without `as_str`.

## Acceptance

1. Every `CancelOutcome` variant has a stable snake_case kind via `as_str`.
2. Tokens never embed run ids, controller refs, or free-form text.
3. Unit tests lock both kinds.
4. Pure `format_cancel_outcome_line` is unit-tested.
5. Local gates and independent review pass.
