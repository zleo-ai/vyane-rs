# WP-265 — Cross-surface native permission token contract

## Outcome

Service-layer unit tests lock that config `NativeToolPermissionEffectConfig` /
`NativeCommandNetworkRouteConfig` tokens match harness
`PermissionEffect` / `NativeCommandNetworkRoute` tokens 1:1, and
`permission_effect` mapping preserves the closed vocabulary.

## Motivation

Config and harness each own a closed allow/ask/deny and network-route enum
(WP-259/260). The service adapter is the shipped bridge; without a contract
test the tables can drift and silently mis-compose permission ceilings.

## Acceptance

1. Unit test asserts `as_str` equality for Allow/Ask/Deny and
   Direct/EnvironmentProxy across config↔harness.
2. Unit test asserts `permission_effect` maps each config effect to the
   harness effect with the same token.
3. Local gates and independent review pass; no CI isolation train.
