# WP-394 — Pure CriterionStatus on goal satisfy/verify

## Outcome

Goal CLI satisfy and verify log pure `format_criterion_status_line` for criterion
status kinds (explicit satisfy always `satisfied`; verify emits each result).

## Motivation

WP-355 published pure criterion status lines. Satisfy/verify still persisted
criterion changes without pure kind messages.

## Acceptance

1. Explicit satisfy logs pure `criterion status: satisfied`.
2. Verify logs pure criterion status for each verification result.
3. Structured `status` fields remain kind-only via `as_str`.
4. `format_criterion_status_line` drops `#[allow(dead_code)]`.
5. Local gates and independent review pass.
