# WP-352 — Kind-only agent completion projection item logs + pure line

## Outcome

Completion publisher logs closed `AgentCompletionProjectionStatus` kind tokens
after each projected event, and CLI ships pure
`format_agent_completion_projection_status_line`.

## Motivation

Supervisor cycle logs already surface first-degraded projection kinds. Per-item
projection settlement still lacked a structured operator signal and a pure
human line (same residual pattern as recovery/execution WP-350/351).

## Acceptance

1. After each projected event settles (including store-failed branches), log `status` as a kind token only.
2. Never log event ids, run ids, digests, or free-form text in that structured log.
3. Pure `format_agent_completion_projection_status_line` is unit-tested.
4. Local gates and independent review pass.
