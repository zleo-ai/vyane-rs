# WP-117 — multi-thread authorized OpenAI Chat cancel and dual-mock fixtures

## Outcome

Run dual-MockServer redirect and cancellation fixtures in
`authorized_openai_chat` on a two-worker Tokio runtime so delayed targets and
cancel paths stay independently schedulable under suite load.

Production protocol clients and authority behavior do not change.

## Motivation

WP-111–116 covered daemon AgentRun, CLI multi-mock, and coverage dual-path
scheduling. The authorized OpenAI Chat suite still ran dual-mock redirect and
in-flight cancel/delay fixtures on the default current-thread runtime.

## Acceptance

1. Dual-mock redirect and cancellation fixtures use two Tokio workers.
2. Existing assertions remain unchanged.
3. No production code changes.
4. Local targeted runs, gates, review, PR CI, and exact merged-main CI pass.
