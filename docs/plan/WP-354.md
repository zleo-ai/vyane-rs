# WP-354 — Pure delivery/completion/publication status lines

## Outcome

CLI ships pure kind-only human lines for `DeliveryStatus`,
`MessagePublicationStatus`, and `RunCompletionStatus`.

## Motivation

These message/agent completion status enums already publish snake_case `as_str`
tokens used on store and recovery paths, but lacked pure CLI formatters for
tests and operator diagnostics. After WP-353 this was the remaining surveyed
half-landed pure-line gap for message/completion status enums.

## Acceptance

1. Pure `format_delivery_status_line` uses only `DeliveryStatus::as_str`.
2. Pure `format_message_publication_status_line` uses only `MessagePublicationStatus::as_str`.
3. Pure `format_run_completion_status_line` uses only `RunCompletionStatus::as_str`.
4. Unit tests lock one non-trivial token per formatter.
5. Local gates and independent review pass.
