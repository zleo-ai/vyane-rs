# WP-281 — Body-free logs for panicked AgentRun supervisor cycles

## Outcome

Supervisor catch_unwind `Err(_)` arms that increment `panicked_cycles` also
emit a body-free `tracing::warn!` with a closed `reason = "panic"` token
(never panic payload).

## Motivation

Failed and degraded cycles now log kind tokens (WP-273–276). Panic arms only
increment counters, leaving operators blind when a cycle unwinds.

## Acceptance

1. Execution, recovery, completion, and drain panic arms log
   `reason = "panic"` (or equivalent closed token) without formatting the
   panic payload.
2. `panicked_cycles` still increments on those arms.
3. Local gates and independent review pass; no CI isolation train.
