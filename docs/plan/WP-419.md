# WP-419 — AdapterTransport kind tokens on native freeze

## Outcome

`AdapterTransport` exposes public `as_str` / Display tokens, CLI ships pure
`format_adapter_transport_line`, and native target freeze logs that pure line
for the bound transport.

## Motivation

Native AgentRun requires `DirectHttp` transport. The freeze path checked
transport equality without a pure kind diagnostic or stable `as_str` API.

## Acceptance

1. `AdapterTransport::as_str` returns stable snake_case tokens matching serde.
2. `Display` delegates to `as_str`.
3. Pure `format_adapter_transport_line` uses `as_str` + terminal_safe.
4. `target_snapshot` logs pure transport line + `transport = as_str`.
5. Unit tests lock tokens; local gates and independent review pass.
