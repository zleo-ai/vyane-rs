# WP-247 — Session-control error kind_code from ErrorKind::as_str where aligned

## Outcome

`session_control_error_view` uses `ErrorKind::as_str()` for kind codes that
already match domain tokens (`not_found`, `conflict`, `indeterminate`,
`unsupported`). Remapped codes (`invalid_argument`, `storage_error`,
`operation_failed`) stay explicit operator-surface tokens.

## Motivation

WP-246 published ErrorKind tokens. Session-control JSON kind codes should share
domain sources where the public operator contract already matches.

## Acceptance

1. Matching kinds set `kind_code` via `kind.as_str()`.
2. Remapped kinds remain explicit static strings (unchanged contract).
3. Existing session-control unit tests still pass.
4. Local gates and independent review pass; no CI isolation train.
