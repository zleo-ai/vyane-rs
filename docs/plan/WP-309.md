# WP-309 — Workflow error kind line + resident workflow logs

## Outcome

CLI ships a pure `format_workflow_error_kind_line`, and the resident workflow
daemon logs workflow engine failures with `WorkflowError::as_str` kind tokens
instead of free-form Display payloads.

## Motivation

WP-308 published kind tokens. Daemon workflow settlement and API failure logs
still used `error = %error`, which embeds paths and run ids.

## Acceptance

1. `format_workflow_error_kind_line` renders `workflow: <kind>` from domain tokens.
2. Unit tests lock the pure line for payload-bearing variants without secrets.
3. Daemon workflow failure and API failure paths log kind-only tokens (join uses a fixed `join` token).
4. Local gates and independent review pass.
