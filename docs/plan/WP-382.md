# WP-382 — Wire pure workflow/task store lines on daemon workflow API fail

## Outcome

Daemon workflow API error mapping logs pure `format_workflow_error_kind_line` or
`format_task_store_error_kind_line` when the failure is downcastable, otherwise a
fixed internal kind.

## Motivation

The API error path already extracted kind tokens for structured fields but used
a free-form English message. Other daemon workflow paths already use pure lines.

## Acceptance

1. `WorkflowError` downcast logs pure workflow line + `error = as_str`.
2. `TaskStoreError` downcast logs pure task-store line + `error = as_str`.
3. Non-store/non-workflow logs `error = "internal"` without free-form Display payloads.
4. Local gates and independent review pass.
