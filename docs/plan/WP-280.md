# WP-280 — Observation error pure lines + ingress open wire

## Outcome

Pure CLI formatters for `GoalObservationIngressError` /
`GoalObservationRunnerError` kind tokens. Service
`goal_observation_ingress` logs the ingress error kind on open failure.

## Motivation

WP-279 published tokens without human pure lines or a construction-path
diagnostic. Matches the WP-277/278 continuity error train.

## Acceptance

1. `format_goal_observation_ingress_error_kind_line(e)` →
   `goal observation ingress: <as_str>`.
2. `format_goal_observation_runner_error_kind_line(e)` →
   `goal observation runner: <as_str>`.
3. `VyaneService::goal_observation_ingress` logs
   `error = err.as_str()` when open fails.
4. Unit tests lock multi-word tokens; gates + independent review pass.
