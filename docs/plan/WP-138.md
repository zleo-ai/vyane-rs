# WP-138 — isolate native multi-mock failover AgentRun fixture in CI

## Outcome

Run `native_agent_submit_fails_over_and_exact_retry_rejects_chain_drift` in a
fresh CI process for normal and coverage jobs.

Production native failover and exact-retry behavior does not change.

## Motivation

This multi-mock multi-thread native AgentRun fixture drives concurrent Wiremock
targets while polling daemon status. Neighboring multi-thread native AgentRun
fixtures already required process isolation under suite/GHA load.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
