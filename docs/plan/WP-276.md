# WP-276 — Log AgentRun driver construction failures with kind tokens

## Outcome

Supervisor execution and recovery loops log `error = <as_str>` when
`AgentRunExecutionDriver` / `AgentRunRecoveryDriver` construction fails,
instead of discarding `Err(_)`.

## Motivation

WP-275 closed cycle-level `Ok(Err(error))` failures. Driver construction
failures still only increment `failed_cycles` without a kind token, leaving a
blind spot on invalid lease/owner/options paths.

## Acceptance

1. Execution loop `match driver { Err(error) => … }` logs
   `error = error.as_str()` (`AgentExecutionError`).
2. Recovery loop construction `Err(error)` logs
   `error = error.as_str()` (`AgentRecoveryError`).
3. Existing as_str tests remain green; gates + independent review pass.
