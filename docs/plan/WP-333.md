# WP-333 — Kind-only native effect revalidation rejection logs

## Outcome

Native model/tool authority revalidation rejections log `NativeSideEffect`
kind tokens (and a closed reason) without turn/ordinal/revision counters.

## Motivation

WP-326/WP-327 published effect kinds and pure lines. Revalidation still returned
errors silently without a structured kind signal for unsupported or invalid
effects.

## Acceptance

1. Invalid one-based coordinate rejection logs `effect = effect.as_str()` and
   `reason = "invalid_coordinates"`.
2. Unsupported checkpoint/session effects log `effect` kind and
   `reason = "unsupported_effect"`.
3. No turn, ordinal, or sequence counters appear in the structured log fields.
4. Local gates and independent review pass.
