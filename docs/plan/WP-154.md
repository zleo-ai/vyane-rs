# WP-154 — isolate detach cancel finalize fixture in CI

## Outcome

Run `cancel_finalizes_cancelled_and_kills_group` in a fresh CI process for
normal and coverage jobs.

Production detach cancel / process-group kill behavior does not change.

## Motivation

This multi_thread detach cancel fixture kills a long-running worker group and
finalizes cancelled status. Neighboring multi_thread detach and AgentRun
fixtures already required process isolation under suite/GHA load.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
