# WP-216 — Pure A2A error / inbox-more and cancel diagnostic lines

## Outcome

Human A2A error prefix, inbox "more messages" note, and cancel diagnostics for
kill-unfinalized / not-local frontend cancel go through pure helpers with
terminal-safe ids where free text is present.

## Motivation

Remaining operator diagnostics on A2A and cancel paths still used ad-hoc
`eprintln!` without pure coverage.

## Acceptance

1. A2A error and more-messages paths use pure formatters.
2. Kill-unfinalized and not-local cancel diagnostics use pure formatters with
   terminal-safe ids.
3. Unit tests drive the shipped formatters.
4. Local gates and independent review pass; no CI isolation train.
