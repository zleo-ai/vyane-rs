## Outcome

`format_goal_event_kind_line` with structured `kind = as_str`.

## Motivation

WP-400 moved human event columns to `as_str`. Event kinds still lacked a pure
kind diagnostic on the live get/progress projection paths.

## Acceptance

1. Add pure `format_goal_event_kind_line` using `kind.as_str()`.
2. `get` logs pure event-kind line for each event when present.
3. Progress path logs pure event-kind line for the emitted progress event.
4. Unit test asserts stable token text.
5. Human/JSON bodies unchanged.
6. Local gates and independent review pass.
