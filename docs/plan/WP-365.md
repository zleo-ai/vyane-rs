# WP-365 — Wire pure register web tool error lines on native AgentRun

## Outcome

Native AgentRun tool registration logs pure CLI kind lines for
`RegisterWebSearchToolError` and `RegisterWebFetchToolError` when hosted web
tools fail to register, clearing half-landed `dead_code` on those formatters.

## Motivation

WP-313 published pure register web tool error lines. Fresh-native AgentRun still
swallowed registration failures with a silent `Unknown` outcome and no kind
diagnostic.

## Acceptance

1. Web-search registration `Err` logs pure `format_register_web_search_tool_error_kind_line` and structured `error = as_str`.
2. Web-fetch registration `Err` logs pure `format_register_web_fetch_tool_error_kind_line` and structured `error = as_str`.
3. Both pure formatters drop `#[allow(dead_code)]`.
4. Structured fields remain kind-only; no policy/model/allowlist/client payloads.
5. Local gates and independent review pass.
