# WP-223 — Pure REST metadata / goal-read / serve listen operator logs

## Outcome

Remaining high-value `vyane serve` operator diagnostics — metadata settlement
retry, task metadata/dispatch-broadcast classification logs, goal-read
unavailable, task output read failures, and the listen banner with token path —
go through pure formatters.

## Motivation

WP-222 purified task-lifecycle supervisor lines. Adjacent serve stderr still
interpolates metadata, goal-read, and listen banner messages ad-hoc.

## Acceptance

1. Metadata settlement retry, task metadata error, and dispatch/broadcast error
   lines use pure formatters.
2. Goal-read unavailable and worker-failed lines use pure formatters.
3. Task output read and legacy output read failure lines use pure formatters.
4. Serve listening banner (addr + token path) uses a pure formatter.
5. Unit tests drive the shipped formatters with terminal-safe id samples.
6. Local gates and independent review pass; no CI isolation train.
