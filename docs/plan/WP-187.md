# WP-187 — CLI human workflow run summary pure formatter + tests

## Outcome

Local `workflow run/resume` human summary goes through pure
`format_workflow_summary` used by `print_workflow_summary`. Unit tests drive
the shipped formatter with real `WorkflowOutcome` / journal steps.

## Motivation

Last multi-line `println!`-only human path in `output.rs` after WP-179–186
locked list/status/broadcast/session/record surfaces.

## Acceptance

1. `print_workflow_summary` wraps `format_workflow_summary`.
2. Header line uses `workflow_status_name`; journal path is printed.
3. Optional replay line when `journal.replay` is set.
4. Step rows show status, run count, and first non-empty output/error line.
5. Unit tests call the shipped formatter with real domain values.
6. Local gates and independent review pass; no CI isolation train.
