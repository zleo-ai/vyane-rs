# WP-137 — isolate native web-search frozen target fixture in CI

## Outcome

Run `native_web_search_uses_the_separate_frozen_responses_target` in a fresh CI
process for normal and coverage jobs, alongside the other multi-thread native
AgentRun isolations.

Production native web-search target behavior does not change.

## Motivation

Multi-thread native AgentRun fixtures that reach real resident lanes remain
sensitive to suite handoff under GHA load. Writable, command-permission, and
write-permission fixtures are already isolated; this remaining frozen
web-search target case still shared the serialized suite.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
