# WP-312 — Event log and workflow-control pure kind lines

## Outcome

CLI ships pure `format_event_log_error_kind_line` and
`format_workflow_control_error_kind_line` over domain kind tokens.

## Motivation

WP-307/WP-310 published `EventLogError` and `WorkflowControlError` kinds.
Operator/CLI pure surfaces still lacked formatters for those closed enums.

## Acceptance

1. Pure lines render `event log: <kind>` and `workflow control: <kind>`.
2. Unit tests lock representative kinds without embedding secrets.
3. Local gates and independent review pass.
