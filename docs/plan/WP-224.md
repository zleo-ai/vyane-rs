# WP-224 — Pure REST label / stream / broadcast / query operator logs

## Outcome

Remaining `vyane serve` handler-side operator diagnostics for label parsing,
stream dispatch, broadcast setup/target errors, and ledger/session/async query
paths go through pure formatters.

## Motivation

WP-222/223 purified task-supervisor and metadata/goal/serve banners. Handler
stderr for request validation and query failures still uses ad-hoc
interpolations.

## Acceptance

1. Dispatch/stream/broadcast/async label error lines use pure formatters.
2. Stream request/route/dispatch_stream error lines use pure formatters.
3. External task label, broadcast setup/target error lines use pure formatters
   (terminal-safe target free text).
4. Run ledger query and session snapshot query error lines use pure formatters.
5. Unit tests drive the shipped formatters.
6. Local gates and independent review pass; no CI isolation train.
