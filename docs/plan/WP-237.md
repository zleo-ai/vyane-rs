# WP-237 — CLI SandboxArg Display uses domain Sandbox tokens

## Outcome

`SandboxArg`'s `Display` delegates to domain `Sandbox::as_str` via `From`,
eliminating the private CLI string match.

## Motivation

WP-236 published domain Sandbox tokens. CLI clap `SandboxArg` still duplicated
kebab-case labels in its `Display` impl.

## Acceptance

1. `Display for SandboxArg` uses `Sandbox::from(*self).as_str()` (or equivalent).
2. Unit test or existing clap help paths remain green.
3. Local gates and independent review pass; no CI isolation train.
