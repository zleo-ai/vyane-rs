# WP-328 — GoalObservationKind + NativeSessionState tokens

## Outcome

`GoalObservationKind` and `NativeSessionState` publish snake_case kind-only
`as_str` tokens without embedding observation ids, repos, or session ids.

## Motivation

Sibling observation signal kinds and many session enums already expose tokens.
These two closed status surfaces still forced Debug/Display for diagnostics.

## Acceptance

1. Every `GoalObservationKind` variant has a stable snake_case kind via `as_str`.
2. Every `NativeSessionState` variant has a stable snake_case kind via `as_str`.
3. Tokens never embed repos, PR numbers, observation ids, or native session ids.
4. Unit tests lock representative payload-bearing variants.
5. Local gates and independent review pass.
