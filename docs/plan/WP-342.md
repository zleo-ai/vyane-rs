# WP-342 — Kind-only cancel controller recovery observation logs

## Outcome

Daemon agent cancel path logs closed `ControllerRecoveryObservation` kind
tokens when Process/InProcess controllers are observed, without controller
refs or free-form text.

## Motivation

WP-341 published recovery observation kinds. Cancel still had no structured
operator signal for gone vs still_present vs unavailable before settle.

## Acceptance

1. After Process `stop_exact` and InProcess `observe_gone`, log `observation` as a kind token only.
2. Never log controller refs or free-form text in that structured log.
3. Local gates and independent review pass.
