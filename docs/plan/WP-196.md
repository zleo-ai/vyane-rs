# WP-196 — CLI human progress event line pure formatter + tests

## Outcome

Human `vyane goal progress` projects the recorded `GoalEvent` through pure
`format_progress_event_line`: terminal-safe event id / goal id, kind Display
snake_case, and revision. `GoalEventKind` exposes public `as_str`/`Display`.

## Motivation

Progress human mode only printed a terminal-safe event id, omitting kind and
goal/revision context operators need when scripting lifecycle events.

## Acceptance

1. Human progress path uses `format_progress_event_line` (JSON unchanged).
2. Tab line: safe event_id, kind snake_case, safe goal_id, revision.
3. `GoalEventKind` has public `as_str`/`Display`.
4. Unit tests drive the shipped formatter with real `GoalEvent` values.
5. Local gates and independent review pass; no CI isolation train.
