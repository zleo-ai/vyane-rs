# WP-143 — isolate exit-zero-without-terminal process fixture in CI

## Outcome

Run `exit_zero_without_terminal_result_fails_without_completion` in a fresh CI
process for normal and coverage jobs.

Production process-harness completion classification does not change.

## Motivation

This process-lane AgentRun fixture shares suite-handoff sensitivity with the
already isolated process and read-only workdir cases: under suite load status
polling can stall with only the daemon listen line while the body is stable
alone.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
