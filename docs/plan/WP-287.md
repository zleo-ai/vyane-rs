# WP-287 — Pure OwnerContextError line + authentication wire

## Outcome

CLI pure `format_owner_context_error_kind_line` prints `OwnerContextError`
kind tokens. `OwnerContextFactory::authenticate` logs the kind on
authentication failure.

## Motivation

WP-286 published owner-context tokens without a human pure line or shipped
diagnostic. Authentication is the common construction path.

## Acceptance

1. `format_owner_context_error_kind_line(e)` → `owner context: <as_str>`.
2. `OwnerContextFactory::authenticate` logs `error = as_str` on
   authentication failure (kind only).
3. Unit tests lock multi-word tokens; gates + independent review pass.
