# WP-323 — Pure BrokerError kind line

## Outcome

CLI depends on `vyane-broker` and ships pure `format_broker_error_kind_line`
over `BrokerError::as_str` tokens.

## Motivation

WP-306 published broker kinds. CLI pure diagnostics still lacked a formatter
because the binary crate did not depend on `vyane-broker` directly.

## Acceptance

1. `vyane-cli` gains a workspace path dependency on `vyane-broker`.
2. Pure line renders `broker: <kind>` for payload-bearing variants without secrets.
3. Unit tests lock representative kinds.
4. Local gates and independent review pass.
