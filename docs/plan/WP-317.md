# WP-317 — OnError kind tokens

## Outcome

Workflow step `OnError` policy publishes lowercase kind tokens via `as_str` and
`Display`, matching its serde rename.

## Motivation

Other workflow status enums already expose tokens. `OnError` was the remaining
closed policy enum without a public kind surface for logs and human lines.

## Acceptance

1. `OnError::as_str` returns `abort` / `continue`.
2. `Display` matches `as_str`.
3. Unit tests lock both tokens.
4. Local gates and independent review pass.
