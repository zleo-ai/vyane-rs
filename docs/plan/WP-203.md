# WP-203 — CLI human daemon lifecycle pure formatters + tests

## Outcome

Human `vyane daemon` start/status/stop operator lines go through pure helpers:
`format_daemon_already_running_line`, `format_daemon_started_line`,
`format_daemon_running_line`, `format_daemon_stopped_line`.

## Motivation

Daemon control human responses still used ad-hoc `println!` without pure helpers
or unit coverage for the stable operator contract strings.

## Acceptance

1. Start (already-running + started), status (non-JSON), and stop success paths
   use the pure formatters (JSON status unchanged; stderr not-running paths
   unchanged).
2. Line shapes match the prior contract exactly (addr + optional pid).
3. Unit tests drive the shipped formatters.
4. Local gates and independent review pass; no CI isolation train.
