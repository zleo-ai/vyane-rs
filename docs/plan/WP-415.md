# WP-415 — Pure PermissionEffect on native ApprovalRequired settle

## Outcome

CLI ships pure `format_permission_effect_line` and logs `ask` when a native
turn settles on `NativeTurnStop::ApprovalRequired` (permission ask surface).

## Motivation

`PermissionEffect` already has `as_str`. The shipped native AgentRun path maps
`ApprovalRequired` stop kinds to durable failures but did not emit a pure
permission-effect kind diagnostic for the ask terminal.

## Acceptance

1. Pure `format_permission_effect_line` uses `effect.as_str()` + terminal_safe.
2. On native turn settle when stop is `ApprovalRequired`, log pure effect line with `effect = "ask"`.
3. Unit test locks pure tokens for allow/ask/deny.
4. Settlement mapping and failure codes unchanged.
5. Local gates and independent review pass (Linux-only wire via native_agent cfg).
