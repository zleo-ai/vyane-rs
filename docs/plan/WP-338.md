# WP-338 — AdapterOutcome / AdapterFailure kind tokens + pure lines

## Outcome

Broker `AdapterOutcome` and `AdapterFailure` publish snake_case kind-only
`as_str` tokens, and CLI ships pure `format_adapter_outcome_line` /
`format_adapter_failure_line`.

## Motivation

Delivery adapter results carried reply/receipt payloads and free-form reason
codes with no closed kind surface for diagnostics. After WP-337 this was the
remaining surveyed adapter result enum pair without `as_str`.

## Acceptance

1. Every `AdapterOutcome` variant has a stable snake_case kind via `as_str`.
2. Every `AdapterFailure` variant has a stable snake_case kind via `as_str`.
3. Tokens never embed bodies, receipts, reason codes, or delays.
4. Unit tests lock all kinds with secret fixtures.
5. Pure CLI lines are unit-tested.
6. Local gates and independent review pass.
