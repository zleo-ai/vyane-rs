# WP-344 — RunSettlement / TaskSettlement kind tokens + pure lines

## Outcome

Agent `RunSettlement` and task `TaskSettlement` publish snake_case kind-only
`as_str` tokens, and CLI ships pure `format_run_settlement_line` /
`format_task_settlement_line`.

## Motivation

Settlement enums carried failure codes and ledger run ids with no closed
top-level kind surface for diagnostics. After WP-343 these were remaining
surveyed settlement enums without `as_str`.

## Acceptance

1. Every `RunSettlement` variant has a stable snake_case kind via `as_str`.
2. Every `TaskSettlement` variant has a stable snake_case kind via `as_str`.
3. Tokens never embed failure codes or ledger run ids.
4. Unit tests lock the kinds with secret fixtures where payloads exist.
5. Pure CLI lines are unit-tested.
6. Local gates and independent review pass.
