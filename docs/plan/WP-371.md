# WP-371 — Pure + wire AgentMessageCompletionStageError on Process AgentRun

## Outcome

CLI ships pure `format_agent_message_completion_stage_error_kind_line` and wires
it onto Process AgentRun completion staging failures.

## Motivation

`AgentMessageCompletionStageError` already publishes kind tokens. Process
AgentRun completion staging still used a free-form English message with only a
structured kind field.

## Acceptance

1. Pure line renders `completion stage: <as_str>` for closed stage-error kinds.
2. Process AgentRun staging Err logs pure line + structured `stage_error = as_str`.
3. No body/key/message payloads in logs.
4. Unit tests lock multi-word tokens; local gates and independent review pass.
