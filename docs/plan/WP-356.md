# WP-356 — Pure workflow journal/state and continuity-step lines

## Outcome

CLI ships pure kind-only human lines for `JournalStepStatus`, `WorkflowState`,
and `GoalContinuityStepStatus`.

## Motivation

These workflow and continuity step status enums already publish snake_case
`as_str` tokens, but lacked pure CLI formatters for tests and operator
diagnostics. After WP-355 this was the remaining surveyed half-landed pure-line
gap for workflow journal/MCP state and continuity step statuses.

## Acceptance

1. Pure `format_journal_step_status_line` uses only `JournalStepStatus::as_str`.
2. Pure `format_workflow_state_line` uses only `WorkflowState::as_str`.
3. Pure `format_goal_continuity_step_status_line` uses only `GoalContinuityStepStatus::as_str`.
4. Unit tests lock one non-trivial token per formatter.
5. Local gates and independent review pass.
