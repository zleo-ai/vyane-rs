# WP-292 — Remaining native policy error kind tokens

## Outcome

`NativeWritePolicyError`, `NativeFilesystemPolicyError`,
`NativeCommandNetworkPolicyError`, `NativeWebFetchPolicyError`, and
`NativeWebSearchPolicyError` publish snake_case `as_str` tokens with unit
tests locking multi-word kinds.

## Motivation

WP-291 covered command/read policy and tool context. Write, network, and
hosted web policy validation still lack kind tokens for the same P1 native
tool train.

## Acceptance

1. Each listed enum has exhaustive kind-only `as_str`.
2. Unit tests lock multi-word tokens for each enum.
3. Local gates and independent review pass.
