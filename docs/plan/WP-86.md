# WP-86 — Configurable native web search

## Outcome

Add a dedicated `web_search` tool to Vyane's native in-process agent lane.
Search remains disabled unless a submission grants a separate
`native_permissions.web_search` policy.

This is not command networking and it is not a new harness. An admitted search
uses a trusted, separately configured OpenAI Responses target whose hosted web
search capability performs the retrieval. The main native agent may continue
to use an OpenAI Chat target.

## Public policy

```json
{
  "native_permissions": {
    "web_search": {
      "target": "search",
      "allow_domains": ["docs.rs", "github.com"],
      "max_searches": 4,
      "search_context_size": "medium"
    }
  }
}
```

- Omission means that `web_search` is neither advertised nor executable.
- `target` must resolve to one direct HTTP OpenAI Responses target without a
  process harness.
- Omitting `allow_domains` permits public web results from any domain. A
  present list must be non-empty and contains lowercase ASCII DNS names.
  Each entry includes its subdomains.
- A tool call may request a narrower domain list. It cannot widen the frozen
  submission policy.
- `max_searches` limits hosted search/open/find actions in one tool call.
- `search_context_size` is `low`, `medium`, or `high`.
- Approximate user location is intentionally absent from the first slice so a
  search grant does not silently disclose location.

The search target is independently configurable rather than hard-coded to a
commercial search API. Credentials stay in Vyane's trusted provider
configuration and are never passed to the main model, command sandbox, tool
arguments, spool, or model-facing result. Responses search requests explicitly
set `store: false`.

## Permission and enforcement boundary

- `web_search` is independent from `command_execution` and
  `command_network`. Granting one does not grant either of the others.
- Submission resolves and freezes both the main native target and search
  target identities. Resident execution re-resolves them and refuses drift.
- The trusted tool and protocol client revalidate live native authority before
  the search request and before every physical HTTP attempt.
- Provider-returned sources are parsed as URLs and checked against the
  effective domain policy before any answer or source is returned to the main
  model.
- Query, response text, source count, source title, source URL and total tool
  output are bounded.
- Cancellation and the native run deadline cover the search request.
- The first slice supports hosted search through the OpenAI Responses wire
  protocol. Other provider protocols may implement the same provider-neutral
  search capability later.

This follows the same separation used by contemporary coding agents: a
dedicated web tool has its own domain policy, while child-process networking
is controlled below the shell. Disabling the web tool therefore does not claim
to disable `curl`; that remains the job of `command_network`.

- Invalid domains, limits, context size, target bindings and policy widening
  fail closed.
- Wire tests cover the exact Responses request, hosted search limit, allowed

- Tool tests cover omission, registration, narrower call domains, authority
  revocation, cancellation, timeout, off-policy sources and bounded output.
- Resident acceptance covers HTTP submission → main model `web_search` call →
  trusted Responses search target → tool result → durable completion.
- Existing filesystem, command and command-network confinement suites remain
  green.
- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test --workspace`
- The exact PR head receives independent cross-model review and all required
  GitHub checks before merge.

## Explicit exclusions

- no implicit command networking;
- no arbitrary URL fetch tool in this package;
- no hard-coded search vendor endpoint or credential;
- no user-location forwarding;
- no native session resume or approval replay;
- no claim that every OpenAI-compatible Responses endpoint implements hosted
  web search.
