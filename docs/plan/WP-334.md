# WP-334 — Kind-only goal observation ingest logs

## Outcome

Goal observation sink ingest logs closed `GoalObservationKind` and
`GoalObservationStatus` tokens without goal ids, repos, or PR payloads.

## Motivation

WP-328/WP-329 published observation kind tokens and pure lines. Ingest still
returned receipts silently without a structured kind signal for operators.

## Acceptance

1. Successful/unchanged/absent/unavailable ingest paths log `kind` and `status`
   tokens via `as_str`.
2. Pre-record rejection logs the same kind-only fields.
3. Never log observation payloads (repo, PR, observation id) in structured fields.
4. Local gates and independent review pass.
