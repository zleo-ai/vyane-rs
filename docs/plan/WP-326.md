# WP-326 — Native/in-process effect kind tokens

## Outcome

`NativeSideEffect` and `InProcessAgentEffect` publish snake_case kind-only
`as_str` tokens so revalidation and permit paths can report effect classes
without turn/sequence counters.

## Motivation

Effect enums gate live authority revalidation. Operators and diagnostics need
closed kinds without embedding turn, ordinal, or revision counters.

## Acceptance

1. Every `NativeSideEffect` variant has a stable snake_case kind via `as_str`
   (counters stay out).
2. Every `InProcessAgentEffect` variant has a stable snake_case kind via `as_str`.
3. Unit tests lock all kinds on both enums.
4. Local gates and independent review pass.
