# WP-259 — Domain tokens for config native permission/network enums

## Outcome

`NativeToolPermissionEffectConfig` and `NativeCommandNetworkRouteConfig`
expose public `as_str` / `Display`.

## Motivation

These closed config-layer enums are already serde snake_case and drive native
permission/network policy. Domain tokens complete the remaining config closed
vocabulary after diagnostics (WP-245).

## Acceptance

1. Both enums have `as_str` + `Display`.
2. Unit tests lock tokens including multi-word `environment_proxy`.
3. Local gates and independent review pass; no CI isolation train.
