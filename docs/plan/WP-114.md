# WP-114 — multi-thread MockServer native_agent unit fixtures

## Outcome

Run Wiremock-backed unit tests in `native_agent.rs` on a two-worker Tokio
runtime so multi-target failover, delayed wire, and cancellation fixtures stay
independently schedulable under the serialized CLI suite.

Production native AgentRun behavior does not change.

## Motivation

WP-111/113 fixed acceptance-level current-thread mock starvation. The same
crate still hosts multi-mock unit fixtures on the default runtime. Aligning
them removes the remaining sibling of that failure class without production
or budget changes.

## Acceptance

1. Every `native_agent` unit test that constructs a `MockServer` uses two
   Tokio workers.
2. Existing assertions remain unchanged.
3. No production code changes.
4. Local unit runs, gates, review, PR CI, and exact merged-main CI pass.
