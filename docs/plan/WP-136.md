# WP-136 — isolate native write-permission tool-lane fixture in CI

## Outcome

Run `native_write_permission_reaches_the_real_resident_tool_lane` in a fresh CI
process for normal and coverage jobs, alongside the native writable and
command-permission isolations.

Production native write-permission tool-lane behavior does not change.

## Motivation

Sibling resident sandbox fixtures already required process isolation after
suite handoff left AgentRun status/submit paths unresponsive under load. This
remaining multi-thread native write-permission fixture still shared the
serialized CLI suite with those neighbors.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
