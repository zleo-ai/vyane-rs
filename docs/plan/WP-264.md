# WP-264 — Wire native stop/status tokens on shipped paths

## Outcome

1. `ToolInvocationStatus::is_executed` single-sources the turn-driver
   `is_error` flag.
2. CLI pure formatter `format_native_turn_stop_line` prints
   `NativeTurnStop::as_str` (no Debug / no payload).

## Motivation

WP-261/WP-263 published domain tokens for the native ask/stop surface; this
package binds them into shipped code so the vocabulary is not dead API.

## Acceptance

1. Turn driver sets `ToolResultMessage.is_error` via `!status.is_executed()`.
2. `format_native_turn_stop_line` uses `stop.as_str()` for multi-word kinds
   (`approval_required`, `budget_exhausted`).
3. Unit tests lock both seams.
4. Local gates and independent review pass; no CI isolation train.
