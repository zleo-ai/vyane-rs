# WP-251 — Domain tokens for goal next-action view enums

## Outcome

`GoalNextActionKind`, `GoalOperatorCommand`, `GoalSignalKind`, and
`GoalNextReasonCode` on the owner-frozen continuity next-action view expose
public `as_str` / `Display`.

## Motivation

These allowlisted REST/protocol enums already serde snake_case and map 1:1
(except reason codes) from domain continuity projection tokens (WP-228/WP-229).
Publishing service-view tokens keeps human and JSON surfaces on the same closed
vocabulary without free-form reason text.

## Acceptance

1. All four enums have `as_str` + `Display`.
2. Action/command/signal tokens single-source domain `as_str` where variants
   align; reason codes have their own snake_case table.
3. Unit tests lock multi-word tokens.
4. Local gates and independent review pass; no CI isolation train.
