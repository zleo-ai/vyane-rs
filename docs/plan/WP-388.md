# WP-388 — Wire pure RunCompletionStatus on terminal AgentRun view

## Outcome

Daemon AgentRun view assembly logs pure `format_run_completion_status_line`
when a terminal run has a completion status record.

## Motivation

WP-354 published pure run-completion status lines. Terminal view assembly already
loaded completion status for the API surface without a pure kind message.

## Acceptance

1. Terminal runs with `Some(completion_status)` log pure run-completion line + `status = as_str`.
2. Non-terminal views remain silent on this pure line.
3. `format_run_completion_status_line` drops `#[allow(dead_code)]`.
4. Local gates and independent review pass.
