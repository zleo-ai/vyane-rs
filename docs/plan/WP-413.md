# WP-413 — Protocol kind tokens on `vyane check`

## Outcome

`Protocol` exposes public `as_str` / Display tokens, CLI ships pure
`format_protocol_line`, and `vyane check` logs that pure line for each
configured provider while the human provider row uses `as_str`.

## Motivation

Check already printed protocol via Display without a stable `as_str` API or
pure kind diagnostic. Kind-only surface needs explicit tokens on the shipped
check path.

## Acceptance

1. `Protocol::as_str` returns stable snake_case tokens matching serde rename.
2. `Display` delegates to `as_str`.
3. Pure `format_protocol_line` uses `as_str` + terminal_safe.
4. `run_check` logs pure protocol line + `protocol = as_str` per provider.
5. Human provider row uses `protocol.as_str()`.
6. Unit tests lock tokens; local gates and independent review pass.
