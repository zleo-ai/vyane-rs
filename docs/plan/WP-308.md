# WP-308 — WorkflowError kind tokens

## Outcome

`WorkflowError` publishes snake_case kind-only `as_str` tokens so daemon
workflow logs and CLI human lines can report failures without paths, run ids,
or free-form validation problem lists.

## Motivation

Resident workflow control still logs `error = %error` Display strings that embed
paths and run ids. Kind tokens are the prerequisite for kind-only tracing and
pure CLI formatters on this surface.

## Acceptance

1. Every `WorkflowError` variant has a stable snake_case kind token via `as_str`.
2. Tokens never embed paths, run ids, hashes, limits, or validation problem text.
3. Unit tests lock all variants with secret/path fixtures that stay out of tokens.
4. Local gates and independent review pass.
