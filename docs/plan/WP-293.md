# WP-293 — ToolChatValidationError kind tokens

## Outcome

`ToolChatValidationError` publishes snake_case kind-only `as_str` tokens
(field names / call ids / counts stay out of the token).

## Motivation

Bounded typed tool chat validation is a core P1 seam. Failures currently only
expose thiserror Display strings, which can include free-form identifiers.

## Acceptance

1. `ToolChatValidationError::as_str` covers all variants kind-only.
2. Unit tests lock multi-word tokens and assert call-id / field payloads stay
   out of `as_str`.
3. Local gates and independent review pass.
