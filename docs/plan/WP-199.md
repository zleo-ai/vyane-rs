# WP-199 — CLI human A2A send/inbox/read pure formatters + tests

## Outcome

Local A2A human paths project through pure helpers:
`format_a2a_send_line`, `format_a2a_inbox_line`, `format_a2a_read_message`
(all terminal-safe free text). Unit tests drive the shipped formatters.

## Motivation

WP-59 exposed local A2A CLI; human mode still used ad-hoc `println!` without
pure helpers or unit coverage for escape safety on ids/codes/kind/body.

## Acceptance

1. Send/inbox/read human paths use the pure formatters (JSON unchanged).
2. Free text fields are terminal-safe; inbox includes delivery status; read is
   header + body.
3. Unit tests call the shipped formatters with real `MessageView` values.
4. Local gates and independent review pass; no CI isolation train.
