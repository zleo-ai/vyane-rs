# WP-275 — Supervisor cycle failure kind tokens on failed cycles

## Outcome

`AgentRecoveryError`, `AgentCompletionPublisherError`, and
`AgentSupervisorError` publish snake_case `as_str` tokens. Supervisor
failed-cycle branches log `error = <as_str>` instead of discarding the Err
with `_`.

## Motivation

WP-273/274 surface degraded *item* kinds. Construction/claim failures on a
cycle still only increment `failed_cycles` without a closed error kind,
leaving operators blind to why a cycle failed.

## Acceptance

1. `AgentRecoveryError::as_str` covers all variants.
2. `AgentCompletionPublisherError::as_str` covers all variants.
3. `AgentSupervisorError::as_str` covers all variants.
4. Supervisor `Ok(Err(error))` paths for execution/recovery/completion log
   `error = error.as_str()` (kind only) when incrementing failed_cycles.
5. Unit tests lock multi-word tokens; gates + independent review pass.
