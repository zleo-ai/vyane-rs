# WP-269 — Emit native turn stop pure line on settlement

## Outcome

Native agent settlement failure path emits
`format_native_turn_stop_line` via `tracing::info!` (stop kind token only),
replacing the WP-268 reachability `let _ =` half-land.

## Motivation

WP-268 landed the pure human formatter and touched settlement only to keep the
symbol reachable. Operators watching daemon logs still need the closed
`NativeTurnStop` vocabulary on the real failure path (parallel to WP-267
wiring tool status onto stream stderr).

## Acceptance

1. On settlement failure (mapped `RunFailureCode`), the path logs
   `format_native_turn_stop_line(&stop)` with `stop_kind` / `failure_code`
   fields from `as_str` tokens — no reply/approval payloads.
2. No `let _ = format_native_turn_stop_line` remain.
3. Existing pure formatter unit tests stay green; local gates and independent
   review pass; no CI isolation train.
