# WP-246 — Domain as_str / Display for ErrorKind

## Outcome

`ErrorKind` exposes public `as_str` / `Display` with serde snake_case tokens
(including `rate_limited`, `spawn_failed`, `harness_failed`).

## Motivation

Session-control and failover surfaces use `ErrorKind` in human/JSON diagnostics.
Domain tokens enable pure formatters without private match tables.

## Acceptance

1. `ErrorKind::as_str` + `Display` cover all named variants; `Other` token is
   `other`.
2. Unit tests lock multi-word tokens.
3. Local gates and independent review pass; no CI isolation train.
