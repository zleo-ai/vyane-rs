# WP-405 — Pure OnError policy on review workflow build

## Outcome

`build_review_workflow` logs pure `format_on_error_policy_line` with structured
`policy = as_str` for each step's closed `OnError` policy when the review
pipeline is constructed.

## Motivation

WP-321 published pure OnError policy lines without a production host. The
built-in multi-model review workflow freezes per-step `OnError` at construction
time and is a real CLI path.

## Acceptance

1. After assembling review steps, log pure on_error policy line + `policy = as_str` for each step.
2. Clear `#[allow(dead_code)]` on `format_on_error_policy_line`.
3. Workflow structure and step policies unchanged.
4. Local gates and independent review pass.
