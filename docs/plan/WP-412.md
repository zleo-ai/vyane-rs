# WP-412 — Pure final GoalStatus on CLI pursue settle

## Outcome

`outcome.final_goal_status` alongside the existing pure pursuit-status line.

## Motivation

(`final_goal_status`) is a separate closed `GoalStatus` already on the outcome
and was not pure-logged on the CLI settle path (print_goal_line covers other
projections only).

## Acceptance

1. After successful pursue, log pure goal-status line for `final_goal_status` + `status = as_str`.
2. Existing pure pursuit-status log remains.
3. JSON/human bodies unchanged.
4. Local gates and independent review pass.
