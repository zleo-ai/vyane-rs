# WP-255 — Domain tokens for AuthStyle and InheritMode

## Outcome

`AuthStyle` and `InheritMode` expose public `as_str` / `Display`.

## Motivation

These closed four-layer / env-policy enums are already serde snake_case and
appear on provider resolution and harness spawn. Domain tokens continue the
kernel closed-vocabulary train after store string enums (WP-241/253/254).

## Acceptance

1. Both enums have `as_str` + `Display` (`bearer`, `x_api_key`, `scrub`, `full`).
2. Unit tests lock tokens (especially multi-word `x_api_key`).
3. Local gates and independent review pass; no CI isolation train.
