# WP-372 — Pure lifecycle observation lines on Process AgentRun

## Outcome

CLI ships pure `format_lifecycle_observation_line` and wires it onto Process
AgentRun dispatch/stop-proof diagnostics that already emit
`LifecycleObservation` kind fields.

## Motivation

WP-271 published lifecycle tokens on Process AgentRun logs. Free-form English
messages remained; pure kind lines were missing.

## Acceptance

1. Pure line renders `lifecycle: <as_str>` (cycle counts stay out of the token).
2. Dispatch-without-quiescence and success-without-stop-proof logs use pure line + structured `lifecycle = as_str`.
3. Unit tests lock all four kinds; local gates and independent review pass.
