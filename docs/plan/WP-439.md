# WP-439 — Pure RunStatus on broadcast table print

## Outcome

CLI logs pure `format_run_status_line` for each successful broadcast row when
printing the human broadcast table.

## Motivation

WP-438 covers history record print. Broadcast success rows also carry closed
`RunStatus` without a pure kind diagnostic.

## Acceptance

1. Reuse pure `format_run_status_line` (`as_str` + `terminal_safe`).
2. `print_broadcast_table` logs pure status for each row with `Some(record)`.
3. Error rows do not invent a run-status log.
4. Human broadcast table shape unchanged.
5. Local gates and independent review pass.
