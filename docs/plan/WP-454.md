# WP-454 — Pure GoalContinuitySignalKind on continuity-execute prompt evidence

## Outcome

CLI `goal continuity-execute` logs pure `format_goal_continuity_signal_kind_line`
for each durable ready signal included in execute prompt evidence assembly.

## Motivation

WP-451 covers ready signals on continuity-next. Continuity-execute already copies
`plan_snapshot.ready_signals` into the operator/runtime prompt via
`append_signal_evidence` without pure-logging those closed kinds.

## Acceptance

1. Reuse pure `format_goal_continuity_signal_kind_line` (no new private table).
2. `append_signal_evidence` logs pure line + `kind = as_str` for each ready signal.
3. Empty ready signals emit no extra pure logs.
4. Prompt text body shape unchanged.
5. Local gates and independent review pass.
