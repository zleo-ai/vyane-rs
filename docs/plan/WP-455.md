# WP-455 — Pure JournalStepStatus on local workflow summary print

## Outcome

CLI local `workflow run/resume` summary print logs pure
`format_journal_step_status_line` for each journal step status.

## Motivation

WP-437 covers pure workflow run status on the same summary host. Daemon
settle already pure-logs journal step status (WP-389). Local human summary
renders step statuses with `as_str` but did not pure-log those closed kinds.

## Acceptance

1. Reuse pure `format_journal_step_status_line` (no new private table).
2. `print_workflow_summary` logs pure line + `status = as_str` for each step.
3. Existing pure workflow run-status log (WP-437) remains.
4. Human summary table shape unchanged.
5. Local gates and independent review pass.
