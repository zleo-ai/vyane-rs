# WP-335 — Kind-only MCP workflow control error mapping logs

## Outcome

MCP public error mapping for `WorkflowControlError` logs closed kind tokens
before returning the allowlisted public error code/message.

## Motivation

WP-310/WP-312 published control-error kinds and pure lines. Mapping to public
MCP errors still had no structured kind-only operator signal.

## Acceptance

1. `PublicError::workflow_control` logs `error = error.as_str()` before mapping.
2. Public error codes/messages remain allowlisted (unchanged contract).
3. Local gates and independent review pass.
