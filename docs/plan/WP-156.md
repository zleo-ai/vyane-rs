# WP-156 — isolate detached auto-route freeze fixture in CI

## Outcome

Run `detached_auto_route_freezes_profile_effort_and_labels` in a fresh CI
process for normal and coverage jobs.

Production detached auto-route freeze behavior does not change.

## Motivation

This multi_thread detach fixture freezes profile/effort/labels while a delayed
Wiremock target serves the worker. Neighboring multi_thread detach fixtures
already required process isolation under suite/GHA load.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
