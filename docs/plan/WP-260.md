# WP-260 — Domain tokens for harness permission/network enums

## Outcome

`PermissionEffect` publishes public `as_str` (Display already present), and
`NativeCommandNetworkRoute` exposes public `as_str` / `Display`.

## Motivation

Native permission effects and command network routes already serde snake_case
and mirror config-layer tokens (WP-259). Domain tokens align harness runtime
vocabulary with config.

## Acceptance

1. `PermissionEffect::as_str` is public; `NativeCommandNetworkRoute` has
   `as_str` + `Display`.
2. Unit tests lock tokens (`allow`/`ask`/`deny`, `direct`/`environment_proxy`).
3. Local gates and independent review pass; no CI isolation train.
