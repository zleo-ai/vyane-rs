# WP-258 — Domain tokens for MCP workflow closed enums

## Outcome

`WorkflowState` and `WorkflowFailureCode` on the MCP workflow control surface
expose public `as_str` / `Display`.

## Motivation

These allowlisted MCP workflow projection enums already serde snake_case.
Domain tokens continue the operator vocabulary train after store and kernel
packages.

## Acceptance

1. Both enums have `as_str` + `Display`.
2. Unit tests lock multi-word tokens (`timed_out`, `dispatch_failed`,
   `control_unavailable`, `lease_expired`).
3. Local gates and independent review pass; no CI isolation train.
