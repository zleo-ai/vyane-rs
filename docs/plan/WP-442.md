# WP-442 — Pure Sandbox on permission check print

## Outcome

CLI logs pure `format_sandbox_line` for the CLI-harness max sandbox when
printing the human permissions check block.

## Motivation

`print_permission_check` already logs pure native axis statuses. The harness
max sandbox token is embedded in the multi-line body without a pure kind log
(WP-426 covered process AgentRun freeze only).

## Acceptance

1. Reuse pure `format_sandbox_line` (`as_str` + `terminal_safe`).
2. `print_permission_check` logs pure sandbox line + `sandbox = as_str` for
   `permissions.harness.max_sandbox`.
3. Existing pure native axis logs remain.
4. Human permissions block shape unchanged.
5. Local gates and independent review pass.
