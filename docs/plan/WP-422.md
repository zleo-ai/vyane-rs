# WP-422 — Pure ExecutionBackend on AgentRun submit freeze

## Outcome

CLI ships pure `format_execution_backend_line` and logs it when freezing a
daemon AgentRun root with a closed `ExecutionBackend`.

## Motivation

`ExecutionBackend` already has stable snake_case tokens. Process and native
AgentRun submit paths freeze the backend into `NewAgentRun` without a pure
kind diagnostic.

## Acceptance

1. Pure `format_execution_backend_line` uses `backend.as_str()` + `terminal_safe`.
2. When process AgentRun submit freezes `CliHarnessProcess`, log pure line +
   `execution_backend = as_str`.
3. When native AgentRun submit freezes `NativeInProcess`, log pure line +
   `execution_backend = as_str`.
4. Unit tests lock representative tokens; create mapping unchanged.
5. Local gates and independent review pass.
