# WP-256 — Domain tokens for EnvInjectSource and ledger event enums

## Outcome

`EnvInjectSource`, `EventCategory`, `EventSource`, and `EventDurability`
expose public `as_str` / `Display`.

## Motivation

Provider env-injection and the owner-scoped event log already use closed
serde snake_case (or fixed durability labels). Domain tokens continue the
kernel/config vocabulary train after WP-255.

## Acceptance

1. All four enums have `as_str` + `Display`.
2. Unit tests lock multi-word tokens (`base_url`, `api_key`) and durability
   labels (`buffered`, `durable`).
3. Local gates and independent review pass; no CI isolation train.
