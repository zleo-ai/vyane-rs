# WP-306 — BrokerError kind tokens

## Outcome

`BrokerError` publishes snake_case kind-only `as_str` tokens so broker
supervisor diagnostics can report failures without nested store payloads or
adapter names.

## Motivation

Message and agent stores already expose kind tokens. The broker wraps those
surfaces plus config/join/event failures and still only has free-form Display.

## Acceptance

1. Every `BrokerError` variant has a stable snake_case kind token via `as_str`.
2. Nested store/event/join payloads and adapter names stay out of tokens.
3. Unit tests lock representative variants including payload-bearing ones.
4. Local gates and independent review pass.
