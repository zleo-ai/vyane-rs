# WP-337 — Kind-only agent cancel settlement logs

## Outcome

Daemon agent cancel path logs closed `CancelOutcome` kind tokens after durable
`settle_cancel`, without run ids or controller refs.

## Motivation

WP-336 published cancel outcome kinds. Settlement still had no structured
operator signal when cancel resolved as cancelled vs controller unavailable.

## Acceptance

1. After successful `settle_cancel`, log `outcome` as a kind token only.
2. Never log run ids, controller refs, or free-form text in that structured log.
3. Local gates and independent review pass.
