# WP-345 — AgentExecutionSettlement kind tokens + pure line

## Outcome

`AgentExecutionSettlement` publishes snake_case kind-only `as_str` tokens, and
CLI ships pure `format_agent_execution_settlement_line`.

## Motivation

Executor settlement outcomes carried staged completion payloads and failure
codes with no closed top-level kind surface. After WP-344 this was the remaining
surveyed execution-settlement enum without `as_str`.

## Acceptance

1. Every `AgentExecutionSettlement` variant has a stable snake_case kind via `as_str`.
2. Tokens never embed staged completions or failure codes.
3. Unit tests lock kinds.
4. Pure `format_agent_execution_settlement_line` is unit-tested.
5. Local gates and independent review pass.
