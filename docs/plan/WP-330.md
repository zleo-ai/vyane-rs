# WP-330 — NackDisposition kind tokens + pure line

## Outcome

`NackDisposition` publishes snake_case kind-only `as_str` tokens, and CLI ships
pure `format_nack_disposition_line`.

## Motivation

Message nack dispositions carried delay and failure-code payloads with no closed
kind surface for diagnostics. After WP-329 this was the remaining surveyed
status/disposition enum without `as_str`.

## Acceptance

1. Every `NackDisposition` variant has a stable snake_case kind via `as_str`.
2. Tokens never embed delays or free-form failure codes.
3. Unit tests lock both kinds with secret failure-code fixtures.
4. Pure `format_nack_disposition_line` is unit-tested.
5. Local gates and independent review pass.
