# WP-273 — AgentExecutionItemStatus / Error kind tokens + degraded log

## Outcome

`AgentExecutionItemStatus` and `AgentExecutionError` publish snake_case
`as_str` tokens. Supervisor execution cycle logs the first degraded item
kind when a batch is not fully settled.

## Motivation

Execution item statuses are body-free closed enums but only compared in
code; operator daemon logs never surface which degraded kind drove backoff.
Stage-error style tokens (WP-272) already proved the diagnostic pattern.

## Acceptance

1. `AgentExecutionItemStatus::as_str` covers all variants
   (`settled`, `controller_unknown`, `settlement_failed`, …).
2. `AgentExecutionError::as_str` covers all construction/claim variants
   (`invalid_owner`, `claim_store_failed`, …).
3. On execution cycle with degraded > 0, supervisor logs
   `first_degraded = <as_str>` (kind only).
4. Unit tests lock multi-word tokens; gates + independent review pass.
