# WP-347 — AgentCompletionSink observation/transition kind tokens + pure lines

## Outcome

`AgentCompletionSinkObservation` and `AgentCompletionSinkTransition` publish
snake_case kind-only `as_str` tokens, and CLI ships pure formatters for both.

## Motivation

Completion sink inspect/publish/discard results were closed unit enums without a
kind surface for diagnostics. After WP-346 these were remaining surveyed
completion-sink enums without `as_str`.

## Acceptance

1. Every `AgentCompletionSinkObservation` variant has a stable snake_case kind via `as_str`.
2. Every `AgentCompletionSinkTransition` variant has a stable snake_case kind via `as_str`.
3. Tokens never embed digests, keys, or free-form text.
4. Unit tests lock all kinds.
5. Pure CLI lines are unit-tested.
6. Local gates and independent review pass.
