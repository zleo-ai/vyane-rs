# WP-184 — CLI human session view line pure formatter + tests

## Outcome

Human owner-scoped session list/inspect lines go through pure
`format_session_view_line` used by `print_session_view_line`. Unit tests drive
the shipped formatter via real `SessionView` (from `SessionSnapshot`).

## Motivation

WP-179–183 locked task/workflow/broadcast/history human projections. Session
view lines still used only `println!` despite already applying `terminal_safe`
and native resume flags.

## Acceptance

1. `print_session_view_line` wraps `format_session_view_line`.
2. Line includes runs, revision, native state name, native_resume available|disabled.
3. Session id / target pass through `terminal_safe` (no raw control sequences).
4. Unit tests call the shipped formatter with real `SessionView` values.
5. Local gates and independent review pass; no CI isolation train.
