# WP-126 — multi-thread remaining MockServer detached CLI fixtures

## Outcome

Run the remaining MockServer-backed detached CLI acceptance fixtures on a
two-worker Tokio runtime so wiremock-backed dispatch/cancel paths stay
independently schedulable under suite load.

Production detach/dispatch behavior does not change.

## Motivation

WP-122 multi-threaded long-delay detach fixtures. Other MockServer-backed
detach cases (auto-route, frontier filter, config/label rejection, legacy job
reader, and task list) still used the default current-thread runtime.

## Acceptance

1. Named remaining MockServer detach fixtures use two Tokio workers.
2. Existing assertions remain unchanged.
3. No production code changes.
4. Local targeted runs, gates, review, PR CI, and exact merged-main CI pass.
