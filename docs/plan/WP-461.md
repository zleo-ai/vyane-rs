# WP-461 — Pure NativeTurnStop / ErrorKind on native cancel Unknown path

## Outcome

Native AgentRun cancel paths that return `AgentExecutorOutcome::Unknown`
(without a quiesced failure) pure-log the closed stop kind or error kind
before leaving reconciliation in charge.

## Motivation

WP-268 pure-logs stop kinds only when a durable failure settlement is chosen.
Cancelled stops and `ErrorKind::Cancelled` model errors intentionally skip
quiesced failure (no false failure code) but also skipped pure kind
diagnostics. Operators then lost the closed cancel token on the shipped settle
path.

## Acceptance

1. When `settlement_for_native_turn_stop` returns `None`, pure-log
   `format_native_turn_stop_line` + `stop_kind = as_str` before Unknown.
2. When model/turn `ErrorKind::Cancelled`, pure-log
   `format_error_kind_line_token` + `error = as_str` before Unknown.
3. Still return Unknown (no false failure settlement).
4. Existing pure logs on quiesced-failure stop path unchanged.
5. Local gates and independent review pass.
