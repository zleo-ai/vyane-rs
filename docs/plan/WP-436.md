# WP-436 — Pure WorkflowRunStatus on workflow list print

## Outcome

CLI logs pure `format_workflow_run_status_line` for each row when printing the
workflow list human table.

## Motivation

`WorkflowRunStatus` pure lines exist on worker finish and daemon workflow
status. The CLI workflow list path embeds status names without pure kind logs
per row.

## Acceptance

1. Reuse pure `format_workflow_run_status_line` (`as_str` + `terminal_safe`).
2. `print_workflow_list` logs pure status for each list row.
3. Human workflow list table shape unchanged.
4. Existing WorkflowRunStatus unit asserts remain green.
5. Local gates and independent review pass.
