# WP-183 — CLI human run record line pure formatter + tests

## Outcome

Human one-line run projection (`history` / dispatch result) goes through pure
`format_record_line` used by `print_record_line`. Unit tests drive the shipped
formatter with real `RunRecord` values.

## Motivation

WP-179–182 locked list/status/broadcast/workflow list human tables. The
history/dispatch one-line record projection still used only `println!`.

## Acceptance

1. `print_record_line` is a thin wrapper over `format_record_line`.
2. Line includes short run id, started_at, target selector, status name, duration.
3. Optional cost renders only when `cost_usd` is `Some`.
4. Unit tests call the shipped formatter with real `RunRecord`.
5. Local gates and independent review pass; no CI isolation train.
