# WP-99 — refresh rmcp 3.0 patch release

## Outcome

Refresh the locked `rmcp` and `rmcp-macros` packages from 3.0.0 to 3.0.1
without changing Vyane's MCP API, transport, tool set, or authority boundary.

The workspace dependency remains `version = "3.0"` and the Rust 1.88 MSRV is
unchanged.

## Upstream scope

The 3.0.1 release contains protocol-version negotiation, authentication
refresh, streamable HTTP, and subscription metadata fixes. Vyane currently
uses the stdio server/client features rather than the affected HTTP and auth
features, so this package is a compatible lock refresh rather than an API
migration.

## Acceptance

1. `Cargo.lock` resolves `rmcp` and `rmcp-macros` to 3.0.1 without unrelated
   dependency churn.
2. The six-tool library and nine-tool CLI surfaces remain unchanged.
3. Real rmcp duplex tests and CLI-to-MCP-to-authenticated-daemon acceptance
   pass.
4. Format, Clippy, workspace tests, parity, MSRV, independent review, and cloud
   CI pass on the exact committed head.
