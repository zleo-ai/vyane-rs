# WP-213 — Compose workflow error lines from shared config/error helpers

## Outcome

`format_workflow_error_line` delegates to `format_config_error_line` /
`format_error_line` so workflow and generic CLI stderr share one prefix source.

## Motivation

WP-208 and WP-210/212 defined parallel prefix helpers; composing avoids drift
if the operator prefix contract changes.

## Acceptance

1. `format_workflow_error_line` only calls the two shared helpers (no local
   `config error:` / `error:` string templates).
2. Existing unit tests for both workflow and generic prefixes remain green and
   assert the same shapes.
3. Local gates and independent review pass; no CI isolation train.
