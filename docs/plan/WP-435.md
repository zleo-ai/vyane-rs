# WP-435 — Pure WorkflowRunStatus on daemon workflow status print

## Outcome

CLI logs pure `format_workflow_run_status_line` when a daemon workflow view
carries a journal with closed `WorkflowRunStatus`.

## Motivation

`WorkflowRunStatus` already has pure lines on worker finish. Daemon workflow
status print embeds journal status in the human multi-line body without a pure
kind diagnostic.

## Acceptance

1. Reuse pure `format_workflow_run_status_line` (`as_str` + `terminal_safe`).
2. When `view.journal` is `Some`, log pure status line + `status = as_str`.
3. When journal is absent, do not invent a workflow status log.
4. Human daemon workflow view body shape unchanged.
5. Local gates and independent review pass.
