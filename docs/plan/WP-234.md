# WP-234 — Display for SessionNativeState

## Outcome

`SessionNativeState` implements `Display` via existing public `as_str`.

## Motivation

Human session view lines already print `native_state.as_str()`. Adding `Display`
matches the domain token train so formatters can use `{}` consistently.

## Acceptance

1. `impl Display for SessionNativeState` delegates to `as_str`.
2. Unit test locks Display tokens.
3. Local gates and independent review pass; no CI isolation train.
