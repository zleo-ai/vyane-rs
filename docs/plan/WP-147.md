# WP-147 — isolate terminal polling budget fixture in CI

## Outcome

Run `terminal_polling_never_crosses_total_budget` in a fresh CI process for
normal and coverage jobs.

Production terminal polling budget behavior does not change.

## Motivation

This multi_thread Wiremock client-side polling fixture shares suite-handoff
scheduling sensitivity with neighboring daemon AgentRun isolations. Running it
alone keeps total-budget assertions stable under GHA load.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
