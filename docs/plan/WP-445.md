# WP-445 — Pure legacy TaskState on TaskRow::from_legacy

## Outcome

CLI logs pure `format_legacy_task_state_line` when projecting a legacy detached
list row into `TaskRow`.

## Motivation

WP-440 covers detached task status print. Legacy task list projects through
`TaskRow::from_legacy` without pure kind diagnostics for the displayed state.

## Acceptance

1. Reuse pure `format_legacy_task_state_line`.
2. `TaskRow::from_legacy` logs pure line + `state = as_str`.
3. TaskRow string fields and table shape unchanged.
4. Existing unit asserts remain green.
5. Local gates and independent review pass.
