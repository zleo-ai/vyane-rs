# WP-226 — Pure check profile warning + dispatch run-failure lines

## Outcome

`vyane check` profile resolve-warning body and human dispatch run-failure stderr
(no output text, record.error only) go through pure helpers.

## Motivation

Check profile rows still embed `warning: {message}` ad-hoc when failover
resolution fails. Dispatch human paths still print raw `record.error` without a
pure helper (intentionally without an `error:` prefix, but still untested).

## Acceptance

1. Profile resolve failure body uses a pure `warning: …` helper.
2. Dispatch (stream and non-stream) run-failure stderr uses a pure helper that
   preserves the prior no-prefix contract (raw message body only).
3. Unit tests drive both helpers.
4. Local gates and independent review pass; no CI isolation train.
