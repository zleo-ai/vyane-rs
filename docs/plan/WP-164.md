# WP-164 — raise CI test job timeout headroom

## Outcome

Raise the GitHub Actions `test` and `coverage` job `timeout-minutes` from 20
to 30.

Production runtime budgets and test assertions do not change.

## Motivation

Sequential process isolation of multi_thread CLI/daemon fixtures lengthened the
serialized suite. macOS jobs have been cancelled at the previous 20-minute job
ceiling after hang/flake recovery paths, even when healthy runs finish well
under that limit. Extra job-level headroom reduces cancel-on-hang pressure
without widening production budgets.

## Acceptance

1. `test` and `coverage` jobs use `timeout-minutes: 30`.
2. No production code or assertion changes.
3. Local gates, review, PR CI, and exact merged-main CI pass.
