# WP-451 — Pure GoalContinuitySignalKind on continuity-next ready signals

## Outcome

CLI `goal continuity-next` logs pure `format_goal_continuity_signal_kind_line`
for each durable `ready_signals` kind on the continuity state snapshot.

## Motivation

WP-446 covers projected `accepted_signals`. The same host already loads
`continuity_state.ready_signals` (closed `GoalContinuitySignalKind` values
already recorded) without pure kind diagnostics for those ready signals.

## Acceptance

1. Reuse pure `format_goal_continuity_signal_kind_line` (no new private table).
2. `continuity_next` logs pure line + `kind = as_str` for each ready signal when
   continuity state is present.
3. Empty `ready_signals` or absent continuity state emits no ready-signal pure logs.
4. Existing pure accepted-signal logs (WP-446) remain.
5. JSON/human bodies unchanged.
6. Local gates and independent review pass.
