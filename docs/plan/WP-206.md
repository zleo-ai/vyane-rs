# WP-206 — Pure deny / unknown / invalid native tool outputs

## Outcome

Model-facing stop messages for deny, unknown tool, and invalid call go through
pure `denied_tool_output`, `unknown_tool_output`, and `invalid_tool_call_output`
on the shipped prepare path (alongside WP-205 ask outputs).

## Motivation

WP-205 purified the ask surface; deny/unknown/invalid still used inline
`format!` without unit-tested contracts.

## Acceptance

1. Deny / unknown / invalid prepare paths use the pure helpers.
2. Message shapes match the prior ERROR contracts exactly.
3. Unit tests drive the shipped helpers.
4. Local gates and independent review pass; no CI isolation train.
