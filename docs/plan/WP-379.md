# WP-379 — Pure + wire RunFailureCode on AgentRun settle

## Outcome

CLI ships pure `format_run_failure_code_line` and wires it onto native and
Process AgentRun quiesced `Failed { code }` settlements.

## Motivation

`RunFailureCode` already publishes kind tokens. Settle paths logged executor and
execution-settlement kinds but not the nested failure code for `Failed`.

## Acceptance

1. Pure line renders `run failure: <as_str>` for multi-word codes.
2. Native and Process settle helpers log pure failure-code line when settlement is `Failed`.
3. Structured `failure_code` remains kind-only via `as_str`.
4. Unit tests lock multi-word tokens; local gates and independent review pass.
