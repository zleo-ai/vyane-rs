# WP-424 — Pure ControllerKind on AgentRun cancel dispatch

## Outcome

CLI ships pure `format_controller_kind_line` and logs it when daemon AgentRun
cancel dispatches to a live controller by closed `ControllerKind`.

## Motivation

`ControllerKind` already has stable snake_case tokens. Cancel dispatch matches
Process vs InProcess controllers and logs recovery observations without a pure
controller-kind diagnostic.

## Acceptance

1. Pure `format_controller_kind_line` uses `kind.as_str()` + `terminal_safe`.
2. On Process cancel dispatch, log pure kind line + `controller_kind = as_str`.
3. On InProcess cancel dispatch, log pure kind line + `controller_kind = as_str`.
4. Unit tests lock in_process / process / remote tokens; cancel mapping unchanged.
5. Local gates and independent review pass.
