# WP-285 — InProcessAssemblyError kind tokens

## Outcome

`InProcessAssemblyError` publishes snake_case `as_str` tokens covering all
assembly registry failures; unit tests lock multi-word kinds.

## Motivation

WP-284 closed authority/completion/native-bind tokens. Assembly construction
still only has Display prose for invalid owner/metadata/duplicate registry
failures.

## Acceptance

1. `InProcessAssemblyError::as_str` covers all variants.
2. Unit test locks multi-word tokens (`invalid_operation_metadata`,
   `operation_metadata_panicked`, `assembly_registry_unavailable`, …).
3. Local gates and independent review pass.
