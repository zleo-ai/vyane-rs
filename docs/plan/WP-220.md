# WP-220 — Pure worker / stale-detached diagnostic lines

## Outcome

Operator diagnostics for stale detached status, worker metadata settlement,
nested harness controller write/cleanup failures, and output-artifact write
failure go through pure formatters with terminal-safe free text.

## Motivation

After cancel-path purification (WP-216–219), remaining CLI detached-worker
diagnostics still use ad-hoc `eprintln!` interpolations with task ids and paths.

## Acceptance

1. Stale status (worker never wrote status) uses a pure formatter.
2. Worker metadata settlement failure uses a pure formatter.
3. Nested harness controller write/cleanup failures use pure formatters.
4. Output path write failure uses a pure formatter.
5. Unit tests drive the shipped formatters.
6. Local gates and independent review pass; no CI isolation train.
