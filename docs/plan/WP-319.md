# WP-319 — Workflow submit/control client error kind tokens

## Outcome

`WorkflowSubmitError` and `DaemonWorkflowControlError` publish snake_case
kind-only `as_str` tokens for the daemon workflow client surface.

## Motivation

MCP maps these client errors onto `WorkflowControlError` (already tokenized in
WP-310). The CLI-side submit/control enums still lacked kind APIs, so any
future logging would fall back to free-form fields (run ids / reasons).

## Acceptance

1. Every `WorkflowSubmitError` variant has a stable kind via `as_str`.
2. Every `DaemonWorkflowControlError` variant has a stable kind via `as_str`.
3. Tokens never embed run ids or free-form reasons.
4. Unit tests lock all kinds; local gates and independent review pass.
