# WP-204 — Session control error view + empty list / run-id pure formatters

## Outcome

1. Pure `session_control_error_view` + `format_session_control_error_line`
   classify and print human/JSON session control failures.
2. Pure `format_empty_task_list_line` and `format_run_id_line` for empty
   `task list` and detached submit success.

## Motivation

Session control error mapping lived only inside an I/O helper, so exit-code
contract tests could not drive a pure classifier. Empty list and run-id human
lines remained ad-hoc `println!`.

## Acceptance

1. `print_session_control_error` uses `session_control_error_view` (JSON kind /
   message / inspect_before_retry + human `error:` line).
2. Empty task list and detached human submit use pure formatters.
3. Unit tests cover exit codes for NotFound/Conflict/Indeterminate, human line,
   empty list, and terminal-safe run id.
4. Existing `session_control_error_exit_codes_distinguish_uncertain_outcomes`
   remains green.
5. Local gates and independent review pass; no CI isolation train.
