# WP-380 — Wire pure GoalStoreError line on goal supervisor fail

## Outcome

Resident goal supervisor task failure logs pure `format_goal_store_error_kind_line`
when the error is a `GoalStoreError`, otherwise a fixed internal kind.

## Motivation

WP-314/302 used kind-only structured fields for supervisor fail with a free-form
English message. Acquisition already uses pure store lines; supervisor exit
should match.

## Acceptance

1. Supervisor `Err` downcast to `GoalStoreError` logs pure goal-store line + `error = as_str`.
2. Non-store errors log structured `error = "internal"` without free-form Display payloads.
3. Local gates and independent review pass.
