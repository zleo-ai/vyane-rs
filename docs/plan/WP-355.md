# WP-355 — Pure goal pursuit/continuity/approval status lines

## Outcome

CLI ships pure kind-only human lines for `PursuitStatus`, `CriterionStatus`,
`GoalContinuityStatus`, and `TakeoverApprovalStatus`.

## Motivation

These goal-domain status enums already publish snake_case `as_str` tokens used
on daemon goal/continuity paths, but lacked pure CLI formatters for tests and
operator diagnostics. After WP-354 this was the remaining surveyed half-landed
pure-line gap for goal pursuit/continuity statuses.

## Acceptance

1. Pure `format_pursuit_status_line` uses only `PursuitStatus::as_str`.
2. Pure `format_criterion_status_line` uses only `CriterionStatus::as_str`.
3. Pure `format_goal_continuity_status_line` uses only `GoalContinuityStatus::as_str`.
4. Pure `format_takeover_approval_status_line` uses only `TakeoverApprovalStatus::as_str`.
5. Unit tests lock one non-trivial token per formatter.
6. Local gates and independent review pass.
