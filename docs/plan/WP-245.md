# WP-245 — Domain tokens for configuration diagnostic enums

## Outcome

`ConfigCheckStatus`, `CredentialStatus`, `ProfileCheckStatus`, and
`ConfigIssueCode` expose public `as_str` / `Display`.

## Motivation

These enums are already serde snake_case diagnostic surfaces. Domain tokens
enable pure human formatters without private CLI match tables.

## Acceptance

1. All four enums have `as_str` + `Display`.
2. Unit tests lock representative multi-word tokens.
3. Local gates and independent review pass; no CI isolation train.
