# WP-423 — Pure RunMode on AgentRun submit freeze

## Outcome

CLI ships pure `format_run_mode_line` and logs it when freezing a daemon
AgentRun root with a closed `RunMode`.

## Motivation

`RunMode` already has stable snake_case tokens. Process and native AgentRun
submit paths freeze `mode` into `NewAgentRun` without a pure kind diagnostic
(WP-422 covered execution backend on the same freeze sites).

## Acceptance

1. Pure `format_run_mode_line` uses `mode.as_str()` + `terminal_safe`.
2. When process AgentRun submit freezes `Autonomous`, log pure line +
   `mode = as_str`.
3. When native AgentRun submit freezes `Autonomous`, log pure line +
   `mode = as_str`.
4. Unit tests lock interactive / autonomous tokens; create mapping unchanged.
5. Local gates and independent review pass.
