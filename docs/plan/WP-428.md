# WP-428 — Pure NativeSessionTransition on session reset_native

## Outcome

CLI logs pure `format_native_session_transition_line` when `session reset-native`
succeeds with a closed `Reset` transition kind.

## Motivation

`NativeSessionTransition` already has kind tokens and a pure formatter. The
shipped reset-native command applies a revisioned reset without a pure
transition diagnostic.

## Acceptance

1. Reuse pure `format_native_session_transition_line` (`as_str` + `terminal_safe`).
2. On successful `reset_native_session`, log pure Reset line +
   `transition = "reset"` (revision stays out of the token).
3. Existing unit tests for transition tokens remain green.
4. Reset mapping / session view shape unchanged.
5. Local gates and independent review pass.
