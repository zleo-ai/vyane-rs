# WP-437 — Pure WorkflowRunStatus on workflow summary print

## Outcome

CLI logs pure `format_workflow_run_status_line` when printing a workflow run
summary (local `workflow run` human path).

## Motivation

WP-435/436 cover daemon status and list pure status logs. The local workflow
summary printer still embeds status without a pure kind diagnostic.

## Acceptance

1. Reuse pure `format_workflow_run_status_line` (`as_str` + `terminal_safe`).
2. `print_workflow_summary` logs pure status + `status = as_str`.
3. Human multi-line workflow summary shape unchanged.
4. Existing unit asserts remain green.
5. Local gates and independent review pass.
