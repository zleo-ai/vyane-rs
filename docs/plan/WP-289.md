# WP-289 — Completion-read and DiagnosticErrorKind tokens

## Outcome

`AgentMessageCompletionReadError` and `DiagnosticErrorKind` publish snake_case
`as_str` tokens; unit tests lock multi-word kinds.

## Motivation

Stage errors already have tokens (WP-272). Completion *read* failures and
diagnostics kinds still only expose Display prose.

## Acceptance

1. `AgentMessageCompletionReadError::as_str` covers all variants.
2. `DiagnosticErrorKind::as_str` covers all variants
   (`invalid_input`, `config_invalid`, `budget_exceeded`).
3. Unit tests lock multi-word tokens.
4. Local gates and independent review pass.
