# WP-282 — NativePermissionSetError kind tokens

## Outcome

`NativePermissionSetError` publishes snake_case `as_str` tokens for the
closed native permission validation failures (`invalid_policy`,
`network_without_command`, `write_outside_sandbox`, `exceeds_ceiling`).

## Motivation

Native permission ceilings are a core P1 seam. Validation already returns a
closed enum, but operators and adapters only see Display prose. Kind tokens
align with the rest of the permission/ask token train.

## Acceptance

1. `NativePermissionSetError::as_str` covers all four variants.
2. Unit test locks multi-word tokens.
3. Local gates and independent review pass.
