# WP-254 — Public as_str for vyane-agent string enums

## Outcome

The `string_enum!` macro in `vyane-agent` publishes `as_str` as `pub`
(matching WP-241 task and WP-253 message).

## Motivation

Agent run/lifecycle/backend/event tokens already exist as crate-private
`as_str` plus `Display`. Public tokens unlock durable human and operator
surfaces on the AgentRun store without re-encoding closed vocabularies.

## Acceptance

1. Macro emits `pub const fn as_str` with doc/`#[must_use]`.
2. Unit test locks multi-word tokens (`timed_out`, `cli_harness_process`,
   `execution_timed_out`, `sink_unavailable`).
3. Local gates and independent review pass; no CI isolation train.
