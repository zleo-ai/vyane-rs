# WP-376 — Wire pure AgentStoreError line on daemon AgentRun create

## Outcome

Daemon native AgentRun create failures that cannot exact-retry log pure
`format_agent_store_error_kind_line` before mapping to conflict/unavailable.

## Motivation

WP-299 published pure agent-store lines (service map_store also logs kinds).
Daemon create still mapped store errors to API codes without a pure CLI line.

## Acceptance

1. Non-retryable create Err logs pure `format_agent_store_error_kind_line` + `error = as_str`.
2. Exact-retry success path stays silent on this branch.
3. `format_agent_store_error_kind_line` drops `#[allow(dead_code)]`.
4. Local gates and independent review pass.
