# WP-295 — Pure tool-chat validation error line + turn-driver wire

## Outcome

CLI pure `format_tool_chat_validation_error_kind_line` prints
`ToolChatValidationError` kinds. Native turn driver logs kind tokens when
request/response validation fails.

## Motivation

WP-293 published tokens. The shipped native turn driver still discards
validation errors without a kind diagnostic.

## Acceptance

1. `format_tool_chat_validation_error_kind_line(e)` →
   `tool chat validation: <as_str>`.
2. Native turn driver logs `error = as_str` on initial request validation
   failure and loop request/response validation failures.
3. Unit tests lock multi-word tokens; gates + independent review pass.
