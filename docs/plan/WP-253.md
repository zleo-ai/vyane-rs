# WP-253 — Public as_str for vyane-message string enums

## Outcome

The `string_enum!` macro in `vyane-message` publishes `as_str` as `pub`
(matching WP-241 for `vyane-task`).

## Motivation

Message direction, endpoint, delivery status, event kind, and publication
status already have crate-private tokens and `Display`. Public `as_str` lets
CLI/API human surfaces reuse the same closed vocabulary without re-encoding.

## Acceptance

1. Macro emits `pub const fn as_str`.
2. Unit test locks multi-word tokens (`dead_lettered`, `lease_renewed`).
3. Local gates and independent review pass; no CI isolation train.
