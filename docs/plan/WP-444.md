# WP-444 — Pure task kinds when projecting TaskRow from durable records

## Outcome

CLI logs pure task state/origin/kind (and failure when present) when projecting
a durable `TaskRecord` into a list `TaskRow` (the path behind `task list`).

## Motivation

WP-431–433 cover durable status print. Task list projects through
`TaskRow::from_record` without pure kind diagnostics before the string table
is rendered.

## Acceptance

1. Reuse pure state/origin/kind/failure format lines.
2. `TaskRow::from_record` logs pure lines for closed enums on the record.
3. Failure log only when `failure_code` is `Some`.
4. TaskRow string fields and table shape unchanged.
5. Local gates and independent review pass.
