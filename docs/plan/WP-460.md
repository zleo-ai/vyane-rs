# WP-460 — Pure ToolInvocationStatus on native ApprovalRequired settle

## Outcome

Native AgentRun ask settle logs pure `format_tool_invocation_status_line` for
`ToolInvocationStatus::ApprovalRequired` alongside the existing stop-kind and
permission-effect pure lines.

## Motivation

WP-91 freezes `ask` so the turn terminates without tool execution. WP-268/415
already pure-log `NativeTurnStop` and `PermissionEffect::Ask` on that settle
path. The closed tool-status token that produced the ask (`approval_required`)
was pure-formatted for stream Executed progress only, not on the ask settle
host.

## Acceptance

1. Reuse pure `format_tool_invocation_status_line` (no new private table).
2. On `NativeTurnStop::ApprovalRequired` settle, pure-log tool status line +
   `status = as_str` for `ApprovalRequired`.
3. Existing pure stop-kind (WP-268) and PermissionEffect::Ask (WP-415) logs remain.
4. Unit tests keep locking the `approval_required` tool-status token.
5. Settlement failure codes and behavior unchanged.
6. Local gates and independent review pass.
