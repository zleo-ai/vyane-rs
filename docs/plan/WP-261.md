# WP-261 — Domain tokens for ToolInvocationStatus (native ask surface)

## Outcome

`ToolInvocationStatus` exposes public `as_str` / `Display` for the closed
native tool-invocation lifecycle, including the permission `ask` terminal
(`approval_required`).

## Motivation

Native tool preparation already settles `PermissionEffect::Ask` into
`ToolInvocationStatus::ApprovalRequired` and related fail-closed statuses.
Those variants are the durable vocabulary of the shipped permission/ask
surface, but only exist as Rust enums today. Domain tokens keep operator,
model-facing diagnostics, and future human formatters on one snake_case table.

## Acceptance

1. Every `ToolInvocationStatus` variant has a stable snake_case `as_str`.
2. `Display` single-sources `as_str`.
3. Unit tests lock multi-word tokens (`approval_required`, `invalid_call`,
   `unknown_tool`, `tool_error`, `timed_out`).
4. Local gates and independent review pass; no CI isolation train.
