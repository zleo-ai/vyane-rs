# WP-249 — Domain tokens for goal observation closed enums

`GoalObservationSignalKind`, `GoalObservationStatus`,
`GoalObservationWatcherErrorCode`, and `GoalObservationWatchStatus` expose
public `as_str` / `Display`.

Domain tokens continue the diagnostic train for goal observation surfaces.

2. Unit tests lock multi-word tokens.
