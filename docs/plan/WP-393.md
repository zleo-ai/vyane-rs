# WP-393 — Pure takeover decision/status on goal continuity decide

## Outcome

Goal continuity decide logs pure `format_takeover_decision_line` and
`format_takeover_approval_status_line` after a successful decision.

## Motivation

WP-355/358 published pure takeover decision and approval status lines. Continuity
decide still mapped status to free-form API strings without pure kind messages.

## Acceptance

1. Successful decide logs pure decision line + pure approval status line.
2. Structured `decision` / `status` fields remain kind-only via `as_str`.
3. Both pure formatters drop `#[allow(dead_code)]`.
4. Local gates and independent review pass.
