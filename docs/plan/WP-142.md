# WP-142 — isolate configured native-ceiling fixture in CI

## Outcome

Run `configured_native_ceiling_rejects_an_optional_axis_before_the_model` in a
fresh CI process for normal and coverage jobs.

Production native ceiling rejection behavior does not change.

## Motivation

This multi-thread native AgentRun control-plane fixture starts a resident
daemon and exercises pre-model optional-axis rejection. Neighboring multi-thread
native AgentRun fixtures already required process isolation under suite/GHA
load.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
