# WP-361 — Wire pure cancel outcome and recovery observation lines

## Outcome

Daemon agent cancel path emits pure CLI kind lines as tracing messages for
`CancelOutcome` and `ControllerRecoveryObservation`, clearing half-landed
`dead_code` allowances on those formatters.

## Motivation

WP-336/337 and WP-341/342 published tokens and kind-only structured fields.
Pure lines remained `#[allow(dead_code)]` until a shipped CLI host message
consumed them (same residual pattern as earlier pure→wire packages).

## Acceptance

1. After durable cancel settlement, log includes pure `format_cancel_outcome_line`.
2. After Process/InProcess controller observation, log includes pure
   `format_controller_recovery_observation_line`.
3. Structured fields remain kind-only (`outcome` / `observation` via `as_str`).
4. Pure formatters no longer need `#[allow(dead_code)]`.
5. Local gates and independent review pass.
