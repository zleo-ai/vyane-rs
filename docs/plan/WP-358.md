# WP-358 — Pure takeover decision/run and pursuit checkpoint/segment lines

## Outcome

CLI ships pure kind-only human lines for `TakeoverDecision`, `TakeoverRunStatus`,
`PursuitCheckpointStatus`, and `PursuitSegmentStatus`.

## Motivation

These goal takeover and pursuit detail enums already publish snake_case `as_str`
tokens, but lacked pure CLI formatters. After WP-357 this was the remaining
surveyed half-landed pure-line gap for takeover/pursuit detail statuses.

## Acceptance

1. Pure `format_takeover_decision_line` uses only `TakeoverDecision::as_str`.
2. Pure `format_takeover_run_status_line` uses only `TakeoverRunStatus::as_str`.
3. Pure `format_pursuit_checkpoint_status_line` uses only `PursuitCheckpointStatus::as_str`.
4. Pure `format_pursuit_segment_status_line` uses only `PursuitSegmentStatus::as_str`.
5. Unit tests lock one non-trivial token per formatter.
6. Local gates and independent review pass.
