# WP-145 — isolate restart terminal-controller cleanup fixture in CI

## Outcome

Run `restart_cleans_terminal_controller_left_after_database_commit` in a fresh
CI process for normal and coverage jobs.

Production terminal-controller cleanup on restart does not change.

## Motivation

This process-lane restart-class fixture shares suite-handoff sensitivity with
the already isolated restart settlement and process cancel cases. Under suite
load status polling can stall while the body remains stable alone.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
