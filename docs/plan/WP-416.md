# WP-416 — Pure AuthStyle on native target freeze

## Outcome

CLI ships pure `format_auth_style_line` and logs it when freezing a native
target snapshot that carries an explicit endpoint auth style.

## Motivation

`AuthStyle` already has kind tokens. The native AgentRun freeze path maps
Bearer/XApiKey into durable snapshots without a pure kind diagnostic.

## Acceptance

1. Pure `format_auth_style_line` uses `style.as_str()` + terminal_safe.
2. When `target_snapshot` freezes an auth style, log pure line + `style = as_str`.
3. Unit test locks bearer / x_api_key tokens.
4. Snapshot mapping unchanged.
5. Local gates and independent review pass.
