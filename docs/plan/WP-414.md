# WP-414 — Pure HarnessKind on `vyane check` harness rows

## Outcome

CLI ships pure `format_harness_kind_line` and `vyane check` logs that pure
line for each harness kind while the human harness row uses `as_str`.

## Motivation

Check already prints harness availability via Display. Kind-only pure
diagnostics and explicit `as_str` in the human row close the same gap as
WP-413 for protocol.

## Acceptance

1. Pure `format_harness_kind_line` uses `kind.as_str()` + terminal_safe.
2. `run_check` logs pure harness-kind line + `harness = as_str` per kind.
3. Human harness row uses `kind.as_str()` (not open Display impl on foreign types).
4. Unit test locks pure token text.
5. Local gates and independent review pass.
