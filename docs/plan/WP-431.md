# WP-431 — Pure TaskState on durable task status print

## Outcome

CLI logs pure `format_task_state_line` when printing durable task status
(human `task status` path).

## Motivation

`TaskState` already has pure kind lines used on daemon workflow cancel
observation. The durable task status human path embeds `task.state` via Display
without a pure kind diagnostic log.

## Acceptance

1. Reuse pure `format_task_state_line` (`state.as_str()` + `terminal_safe`).
2. `print_durable_task_status` logs pure line + `state = as_str`.
3. Human multi-line durable status body shape unchanged.
4. Existing TaskState unit asserts remain green.
5. Local gates and independent review pass.
