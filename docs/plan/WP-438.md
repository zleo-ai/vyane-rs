# WP-438 — Pure RunStatus on history/record print

## Outcome

CLI logs pure `format_run_status_line` when printing a history/run record line.

## Motivation

`RunStatus` pure lines exist on process AgentRun paths. The human history
record printer embeds status via `status_name` without a pure kind diagnostic.

## Acceptance

1. Reuse pure `format_run_status_line` (`as_str` + `terminal_safe`).
2. `print_record_line` logs pure status + `status = as_str`.
3. Human one-line record shape unchanged.
4. Existing RunStatus unit asserts remain green.
5. Local gates and independent review pass.
