# WP-430 — Pure TaskSettlement on lease-loss forced Failed settle

## Outcome

CLI logs pure `format_task_settlement_line` when daemon workflow lease loss
forces a `TaskSettlement::Failed` settle (alongside the WP-421 failure-code
line).

## Motivation

WP-421 added pure failure-code diagnostics on lease-loss Forced Failed settle.
The settlement kind itself (`failed`) is only logged on the normal
`finish_worker` path, not on the lease-loss forced path.

## Acceptance

1. Reuse pure `format_task_settlement_line` (`settlement.as_str()` + `terminal_safe`).
2. On lease-loss forced Failed settle, log pure settlement line +
   `settlement = as_str` (with existing pure failure-code line).
3. Forced settlement mapping still `TaskSettlement::Failed { code, .. }`.
4. Existing settlement unit asserts remain green.
5. Local gates and independent review pass.
