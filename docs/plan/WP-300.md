# WP-300 — Register web fetch/search tool error kind tokens

## Outcome

`RegisterWebFetchToolError` and `RegisterWebSearchToolError` publish
snake_case kind-only `as_str` tokens (`policy` / `registry`).

## Motivation

Command registration already has kind tokens (WP-297). Hosted web tool
registration uses the same transparent policy/registry pattern without kinds.

## Acceptance

1. Both register enums have kind-only `as_str` (`policy`, `registry`).
2. Unit tests lock tokens.
3. Local gates and independent review pass.
