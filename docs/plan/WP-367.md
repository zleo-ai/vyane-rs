# WP-367 — Pure + wire PermissionRuleError on native AgentRun

## Outcome

CLI ships pure `format_permission_rule_error_kind_line` and wires it onto native
AgentRun permission-policy assembly failures (workspace / command / web_search /
web_fetch policies and restriction layers).

## Motivation

WP-290 published `PermissionRuleError` kind tokens. Fresh-native AgentRun still
swallowed permission-policy construction and `push_restriction` failures as
silent `Unknown` outcomes.

## Acceptance

1. Pure line renders `permission rule: <as_str>` for closed rule-error kinds.
2. Native AgentRun logs pure line + structured `error = as_str` when
   `workspace_permission_policy`, `command_permission_policy`,
   `web_search_permission_policy`, `web_fetch_permission_policy`, or
   `push_restriction` returns Err.
3. No tool-pattern / regex / layer payload in structured logs.
4. Unit tests lock multi-word tokens; local gates and independent review pass.
