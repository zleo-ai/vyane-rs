# WP-449 — Pure GoalOperatorCommand on REST continuity-next when projected

## Outcome

REST `GET /v1/goals/{id}/continuity-next` logs pure
`format_goal_operator_command_line` when the projected allowlisted
`GoalOperatorCommand` is present.

## Motivation

WP-409 covers CLI operator-command pure residual. WP-448 covers REST action
kind. REST success already materializes optional `command` on
`GoalNextActionView` without a pure kind diagnostic.

## Acceptance

1. Add pure `format_goal_operator_command_line` over `GoalOperatorCommand::as_str`.
2. REST success path logs pure line + `command = as_str` when command is Some.
3. Absent command emits no operator-command pure log.
4. Unit tests lock representative closed command tokens.
5. JSON response body and status mapping unchanged.
6. Local gates and independent review pass.
