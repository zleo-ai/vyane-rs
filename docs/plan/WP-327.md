# WP-327 — Pure native/in-process effect lines

## Outcome

CLI ships pure `format_native_side_effect_line` and
`format_inprocess_agent_effect_line` over WP-326 domain tokens.

## Motivation

WP-326 published effect kinds. Operator pure lines still lacked formatters for
native revalidation and in-process permit effect classes.

## Acceptance

1. Pure lines render `native effect: <kind>` and `inprocess effect: <kind>`.
2. Unit tests lock payload-bearing and unit variants without embedding counters.
3. Local gates and independent review pass.
