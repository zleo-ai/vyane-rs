# WP-343 — AgentExecutorOutcome / ReplaySafety kind tokens + pure lines

## Outcome

`AgentExecutorOutcome` and broker `ReplaySafety` publish snake_case kind-only
`as_str` tokens, and CLI ships pure `format_agent_executor_outcome_line` /
`format_replay_safety_line`.

## Motivation

Executor observation outcomes and adapter replay-safety contracts had no closed
kind surface for diagnostics. After WP-342 these were remaining surveyed
execution/delivery enums without `as_str`.

## Acceptance

1. Every `AgentExecutorOutcome` variant has a stable snake_case kind via `as_str`.
2. Every `ReplaySafety` variant has a stable snake_case kind via `as_str`.
3. Tokens never embed settlement payloads or free-form text.
4. Unit tests lock the kinds.
5. Pure CLI lines are unit-tested.
6. Local gates and independent review pass.
