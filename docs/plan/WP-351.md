# WP-351 — Kind-only agent execution item status logs + pure line

## Outcome

Agent execution driver logs closed `AgentExecutionItemStatus` kind tokens after
each executed claim, and CLI ships pure `format_agent_execution_item_status_line`.

## Motivation

WP-273/supervisor already exposed execution item kinds on cycle-level degraded
logs. Per-item settlement still lacked a structured operator signal and a pure
human line (same residual pattern as recovery WP-350).

## Acceptance

1. After each `execute_one` result, log `status` as a kind token only.
2. Never log run ids, controller refs, or free-form text in that structured log.
3. Pure `format_agent_execution_item_status_line` is unit-tested.
4. Local gates and independent review pass.
