# WP-390 — Wire pure AttemptOutcome on Process AgentRun Error settle

## Outcome

Process AgentRun quiesced Error settlement logs pure `format_attempt_outcome_line`
for the last attempt when present.

## Motivation

WP-340 published pure attempt-outcome lines. Quiesced Error settlement already
inspected the last attempt for SpawnFailed mapping without a pure kind message.

## Acceptance

1. Quiesced Error with a last attempt logs pure attempt line + structured `attempt = as_str`.
2. Quiesced Error without attempts skips the pure line without inventing an outcome.
3. No free-form attempt payloads in structured fields or pure lines.
4. `format_attempt_outcome_line` drops `#[allow(dead_code)]`.
5. Local gates and independent review pass.
