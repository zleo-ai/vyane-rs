# WP-263 — Domain tokens for NativeTurnStop kind

## Outcome

`NativeTurnStop` exposes public `as_str` / `Display` for its closed stop *kind*
tokens (payloads remain redacted).

## Motivation

The native turn driver already maps permission-ask and other fail-closed stops
into `NativeTurnStop`. Operator and daemon paths branch on those variants; a
stable snake_case kind token is the half-landed vocabulary for durable human
surfaces without leaking assistant text or approval plans.

## Acceptance

1. `as_str` returns a stable snake_case kind for every variant
   (`approval_required`, `budget_exhausted`, `aborted_after_tool_activity`, …).
2. `Display` single-sources `as_str` (no payload / Debug).
3. Unit tests lock multi-word tokens; redacted Debug remains for secrets.
4. Local gates and independent review pass; no CI isolation train.
