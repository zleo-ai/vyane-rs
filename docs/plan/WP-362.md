# WP-362 — Wire pure pursuit/goal status lines on resident pursuit settle

## Outcome

Resident goal pursuit settlement logs emit pure CLI kind lines for
`PursuitStatus` and `GoalStatus`, clearing half-landed `dead_code` allowances
on those formatters.

## Motivation

WP-270/355 published pursuit and goal status tokens and pure lines. The resident
pursuit settle path still logged only structured kind fields without consuming
the pure human lines.

## Acceptance

1. After successful resident pursuit settle, log message includes pure
   `format_pursuit_status_line` and pure `format_goal_status_line`.
2. Structured `status` and `final_goal_status` fields remain kind-only via `as_str`.
3. Pure formatters no longer need `#[allow(dead_code)]`.
4. Local gates and independent review pass.
