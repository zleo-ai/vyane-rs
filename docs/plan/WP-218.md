# WP-218 — Pure legacy cancel identity / cleanup diagnostics

## Outcome

Legacy detached cancel's process-identity and nested-harness cleanup diagnostics
go through pure `format_*` helpers with terminal-safe task ids.

## Motivation

The cancel path still had multi-branch identity-gate and cleanup residual
messages built as ad-hoc `eprintln!` interpolations. Those are operator-facing
and need pure formatters for contract tests and terminal safety.

## Acceptance

1. Terminal-metadata cleanup-failed, worker-gone nested cleanup, identity
   mismatch refuse/cleanup-failed, nested harness identity unavailable, leader
   exited / identity-changed before SIGKILL, and incomplete process-group lines
   use pure formatters.
2. Production cancel path in `command.rs` wires those helpers (no remaining
   ad-hoc interpolations on those branches).
3. Unit tests drive the shipped formatters with exact string contracts and a
   control-char / ANSI-safe id sample.
4. Local gates and independent review pass; no CI isolation train.
