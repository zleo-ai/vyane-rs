# WP-434 — Pure task kinds on daemon workflow status print

## Outcome

CLI logs pure task state/origin/kind (and failure code when present) when
printing daemon workflow status views.

## Motivation

WP-431–433 wire pure task kinds on durable `task status`. Daemon workflow
status/submit human paths print `WorkflowTaskView` without those pure kind
diagnostics.

## Acceptance

1. Reuse pure `format_task_state_line`, `format_task_origin_line`,
   `format_task_kind_line`, and `format_task_failure_code_line`.
2. `print_daemon_workflow_view` logs state/origin/kind pure lines.
3. When `view.task.failure_code` is `Some`, also log pure failure code.
4. Human daemon workflow view body shape unchanged.
5. Local gates and independent review pass.
