# WP-243 — Display for RouteTier and RouteEffort

## Outcome

`RouteTier` and `RouteEffort` implement `Display` via existing public `as_str`.

## Motivation

CLI route human formatters already use `.as_str()` on these enums. Adding
`Display` matches the domain token train (WP-242 Effort).

## Acceptance

1. Both enums implement Display via as_str.
2. Unit tests lock tokens.
3. Local gates and independent review pass; no CI isolation train.
