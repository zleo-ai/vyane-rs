# WP-341 — ControllerRecoveryObservation kind tokens + pure line

## Outcome

`ControllerRecoveryObservation` publishes snake_case kind-only `as_str` tokens,
and CLI ships pure `format_controller_recovery_observation_line`.

## Motivation

Controller recovery observations (`Gone` / `StillPresent` / `Unavailable`) drive
cancel and recovery settlement but had no closed kind surface for diagnostics.
After WP-340 this was the remaining surveyed recovery-observation enum without
`as_str`.

## Acceptance

1. Every `ControllerRecoveryObservation` variant has a stable snake_case kind via `as_str`.
2. Tokens never embed controller refs or free-form text.
3. Unit tests lock all three kinds.
4. Pure `format_controller_recovery_observation_line` is unit-tested.
5. Local gates and independent review pass.
