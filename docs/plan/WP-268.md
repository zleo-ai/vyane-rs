# WP-268 — Pure human line for NativeTurnStop kind

## Outcome

CLI pure formatter `format_native_turn_stop_line` prints `NativeTurnStop`
kind tokens; unit tests lock multi-word kinds without payloads.

## Motivation

WP-263/264 published and wired stop kind tokens onto settlement. Operators
still need a pure human line for the same vocabulary (e.g. future diagnostics
and tests), matching the tool-status pure surface (WP-266).

## Acceptance

1. `format_native_turn_stop_line(stop)` → `native turn stop: <as_str>` via
   `terminal_safe`.
2. Unit tests lock `approval_required`, `budget_exhausted`,
   `tool_choice_violation` and assert secrets stay out of Display.
3. Local gates and independent review pass; no CI isolation train.
