# WP-122 — multi-thread long-delay detached CLI acceptance fixtures

## Outcome

Run long-delay MockServer detached CLI acceptance fixtures on a two-worker
Tokio runtime so delayed targets stay independently schedulable while the
parent CLI returns from `--detach` or cancels the worker group.

Production detach/dispatch and task control behavior do not change.

## Motivation

WP-115 multi-threaded multi-mock CLI failover acceptances. Detached CLI
fixtures that prove parent return-before-completion or cancel-while-in-flight
still used the default current-thread runtime with 10–30s Wiremock delays.

## Acceptance

1. Named long-delay detach fixtures use two Tokio workers.
2. Existing assertions remain unchanged.
3. No production code changes.
4. Local targeted runs, gates, review, PR CI, and exact merged-main CI pass.
