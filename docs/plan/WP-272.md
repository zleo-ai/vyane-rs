# WP-272 — Completion-stage and controller-cleanup kind tokens on daemon logs

## Outcome

Process AgentRun completion-stage failures and workflow controller-cleanup
diagnostics log closed snake_case kind tokens / counts instead of Debug
`?staged` / `?report` dumps.

## Motivation

Daemon warn paths still Debug-format `Result` and full cleanup reports. Stage
errors already have a closed enum; cleanup statuses already have serde
snake_case tags. Publishing `as_str` and wiring counts/tokens keeps operator
logs parseable and avoids free-form Debug shapes on the hot recovery path.

## Acceptance

1. `AgentMessageCompletionStageError::as_str` publishes
   `invalid_message` / `runtime_unavailable` / `task_failed` /
   `sink_unavailable` / `rejected`.
2. Process AgentRun staging failure logs `stage_error = err.as_str()` (no
   `?staged`).
3. `ControllerCleanupStatus::as_str` publishes kind-only tokens (no reason /
   message payloads).
4. Workflow cleanup warn paths log `unresolved` count (not `report = ?report`).
5. Unit tests lock multi-word tokens; gates + independent review pass.
