# WP-214 — Compose session-control error line from shared error helper

## Outcome

`format_session_control_error_line` delegates to `format_error_line` so session
control and generic CLI errors share one `error:` prefix source.

## Motivation

Parallel to WP-213's workflow compose; avoids prefix drift across stderr
families.

## Acceptance

1. `format_session_control_error_line` only calls `format_error_line`.
2. Existing session-control unit tests remain green with the same shape.
3. Local gates and independent review pass; no CI isolation train.
