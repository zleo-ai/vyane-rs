# WP-366 — Pure + wire RegisterCommandToolError on native AgentRun

## Outcome

CLI ships pure `format_register_command_tool_error_kind_line` and wires it onto
native AgentRun command-tool registration failures (with and without network
policy), using closed `RegisterCommandToolError` kind tokens.

## Motivation

WP-365 closed silent web tool registration failures. Command tool registration
still discarded errors as `()` and returned `Unknown` with no kind diagnostic.

## Acceptance

1. Pure line renders `register run_command: <as_str>` for command_policy / network_policy / registry kinds.
2. Native AgentRun logs pure line + structured `error = as_str` on command registration Err.
3. No-network path maps `NativeCommandPolicyError` into `RegisterCommandToolError::Command` for unified kind surface.
4. No program/args/mount/network payloads in logs.
5. Unit tests lock pure lines; local gates and independent review pass.
