# WP-315 — Kind-only workflow controller cleanup logs

## Outcome

Resident workflow controller open/cleanup/join failure paths log closed kind
tokens (`controller_cleanup`, `controller_open`, `join`, `invalid_task_id`)
instead of free-form `error = %error` Display strings.

## Motivation

Workflow engine and task-store failures already use kind tokens (WP-309/WP-311).
Harness controller cleanup still logged full anyhow/IO Display on recovery,
lease-loss, cancel grace, terminal, and shutdown paths.

## Acceptance

1. All remaining daemon_workflow controller-related `error = %error` sites use
   fixed kind tokens (no Display payloads).
2. Kind vocabulary is closed: `controller_cleanup`, `controller_open`, `join`,
   `invalid_task_id`.
3. Local gates and independent review pass.
