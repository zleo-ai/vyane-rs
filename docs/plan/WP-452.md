# WP-452 — Pure GoalContinuityStepStatus on continuity-queue ready step

## Outcome

CLI `goal continuity-queue` logs pure `format_goal_continuity_step_status_line`
for the ready, approval-required plan step selected before queueing takeover.

## Motivation

WP-403 covers continuity-next step status projection. Continuity-queue already
selects a closed `GoalContinuityStepStatus::Ready` step on the shipped host
but did not pure-log that step status before freeze.

## Acceptance

1. Reuse pure `format_goal_continuity_step_status_line` (no new private table).
2. `continuity_queue` logs pure line + `status = as_str` for the selected step
   before `queue_takeover_approval`.
3. Existing pure sandbox log on queue (WP-410) remains.
4. JSON/human bodies unchanged.
5. Local gates and independent review pass.
