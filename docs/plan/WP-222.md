# WP-222 — Pure REST task lifecycle operator log lines

## Outcome

`vyane serve` task-supervisor lifecycle operator diagnostics on stderr go
through pure formatters with terminal-safe task ids.

## Motivation

CLI cancel/worker surfaces are largely purified (WP-208–221). REST async task
supervisor still interpolates initialization cleanup, dispatch failure, and
duplicate-runtime diagnostics ad-hoc.

## Acceptance

1. Initialization cleanup read/failed/contended lines use pure formatters.
2. Duplicate runtime dispatch rejection uses a pure formatter.
3. Task dispatch failure, panic, and output-artifact failure use pure
   formatters.
4. Unit tests drive the shipped formatters with terminal-safe id samples.
5. Local gates and independent review pass; no CI isolation train.
