# WP-425 — Pure TaskOrigin and TaskKind on daemon workflow create

## Outcome

CLI ships pure `format_task_origin_line` and `format_task_kind_line`, and logs
them when freezing a daemon workflow `NewTask` with closed origin/kind.

## Motivation

`TaskOrigin` and `TaskKind` already have kind tokens. Daemon workflow submission
freezes `Daemon` / `Workflow` into durable task rows without pure kind
diagnostics.

## Acceptance

1. Pure `format_task_origin_line` uses `origin.as_str()` + `terminal_safe`.
2. Pure `format_task_kind_line` uses `kind.as_str()` + `terminal_safe`.
3. When creating a daemon workflow task, log both pure lines +
   `origin`/`kind` as_str fields.
4. Unit tests lock origin (rest_async/cli_detached/daemon) and kind
   (dispatch/workflow) tokens; create mapping unchanged.
5. Local gates and independent review pass.
