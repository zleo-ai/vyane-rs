# WP-305 — Quota validation/runner/transport error kind tokens

## Outcome

`QuotaValidationError`, `QuotaRunnerError`, and `QuotaTransportError` publish
snake_case kind-only `as_str` tokens for continuity quota handoff diagnostics.

## Motivation

Quota status/unit tokens already exist. The three closed error enums used by
snapshot validation, runner construction, and HTTP transport lacked kind APIs,
so operators would fall back to Display strings.

## Acceptance

1. All three enums expose stable snake_case kind tokens via `as_str`.
2. Field names and free-form payloads stay out of tokens.
3. Unit tests lock every kind.
4. Local gates and independent review pass.
