# WP-262 — Domain tokens for continuity port result and web-search context

## Outcome

`GoalContinuityPortResult` exposes public `as_str` / `Display`, and
`WebSearchContextSize` gains `Display` single-sourced from its existing
`as_str`.

## Motivation

Continuity runner port results already map to redacted run statuses
(`QueueApplied` / `ExecutionUnchanged` / …). Publishing port-result tokens
locks the intermediate closed vocabulary. `WebSearchContextSize` already had
`as_str` without `Display`, leaving a half-landed kernel surface.

## Acceptance

1. `GoalContinuityPortResult` has `as_str` + `Display` for Applied/Unchanged/
   Rejected/Unavailable.
2. `WebSearchContextSize` implements `Display` via `as_str`.
3. Unit tests lock tokens.
4. Local gates and independent review pass; no CI isolation train.
