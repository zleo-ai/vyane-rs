# WP-211 — Route remaining CLI config-error stderr through pure helper

## Outcome

All remaining human `config error:` stderr sites in `command.rs` print through
`format_config_error_line` (including dynamic `{error:#}` and static validation
messages for serve was already WP-210; this package finishes the CLI surface).

## Motivation

WP-210 introduced the pure prefix helper but left most load/phase config errors
on ad-hoc `eprintln!("config error: …")`.

## Acceptance

1. No residual ad-hoc `eprintln!("config error:` literals remain in
   `crates/vyane-cli/src/command.rs`.
2. Dynamic and static config messages use `format_config_error_line`.
3. Existing unit tests for the helper remain green.
4. Local gates and independent review pass; no CI isolation train.
