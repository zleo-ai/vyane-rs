# WP-324 — Pure quota error kind lines

## Outcome

CLI depends on `vyane-quota` and ships pure formatters for
`QuotaValidationError`, `QuotaRunnerError`, and `QuotaTransportError`.

## Motivation

WP-305 published quota error kinds. CLI pure diagnostics still lacked
formatters and a direct dependency on `vyane-quota`.

## Acceptance

1. `vyane-cli` gains a workspace path dependency on `vyane-quota`.
2. Pure lines render `quota validation|runner|transport: <kind>`.
3. Unit tests lock representative kinds without field payloads.
4. Local gates and independent review pass.
