# WP-103 — isolate remaining main lifecycle gates

## Outcome

Keep the exact main-branch macOS and coverage gates deterministic by giving two
already-bounded lifecycle fixtures fresh test-process boundaries.

Production broker, daemon, timeout, recovery, and MCP behavior do not change.

## Failure evidence

Main run `30506376583` at merge commit
`319b9da521e3242b482dff46cf92f676b5f38686` produced two independent failures:

- macOS completed the workspace tests, then stalled in the serialized broker
  `supervisor_contract` process after three of six tests. The next test in
  libtest order was `maintenance_runs_without_delivery_lanes`; the runner
  cancelled the still-live supervisor process at the 20-minute job limit.
- coverage completed the earlier CLI daemon cases, but
  `restart_recovers_exact_controller_without_replay` did not observe its first
  worker invocation inside the fixture's explicit ten-second startup guard.
  The same production recovery path and normal Ubuntu test job passed.

Both fixtures own detached or paused-runtime lifecycle state and are stable in
fresh processes. Increasing production timeouts or weakening assertions would
hide the observed test-process handoff instead of preserving the contract.

## Acceptance

1. The normal broker suite remains serialized and skips only the maintenance
   fixture that is immediately run by exact name in a fresh process.
2. Coverage measures every CLI test, skipping the restart fixture in the batch
   and immediately measuring it by exact name in a fresh process.
3. No test is ignored and no production timeout, authority, or lifecycle
   behavior changes.
4. Formatting, workspace Clippy, the exact split commands, independent review,
   PR CI, and exact merged-main CI pass on their respective immutable heads.
