# WP-228 — Domain snake_case Display for remaining goal continuity/pursuit enums

## Outcome

Remaining goal domain enums used on human/CLI paths expose public `as_str` /
`Display` (matching serde snake_case). The CLI private
`GoalContinuitySignalKind` match table is removed.

## Motivation

WP-189/197 published Display tokens for continuity next-action and event kinds.
Signal kinds and pursuit checkpoint/segment/criterion status still lacked domain
tokens; CLI duplicated signal names in a private match.

## Acceptance

1. `GoalContinuitySignalKind`, `PursuitCheckpointStatus`, `PursuitSegmentStatus`,
   and `CriterionStatus` have public `as_str` + `Display`.
2. CLI signal evidence path uses domain `as_str` (no private match table).
3. Unit tests lock the shipped tokens.
4. Local gates and independent review pass; no CI isolation train.
