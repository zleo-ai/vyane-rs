# WP-401 — Pure continuity status/mode on continuity next

## Outcome

CLI `goal continuity-next` logs pure `format_goal_continuity_status_line` from
the durable continuity state and, when a policy is present, pure
`format_goal_continuity_mode_line`. Human next-action columns use explicit
`as_str` for action and command.

## Motivation

WP-355/357 published pure continuity status and mode lines without a CLI get
host. Continuity next already requires a visible continuity state to project,
so it is a safe real-path wire.

## Acceptance

1. After projecting next action, log pure continuity-status line + `status = as_str` from `continuity_state`.
2. When `continuity_policy` is present, log pure continuity-mode line + `mode = as_str`.
3. `format_continuity_next_action` uses `action.as_str()` and `command.as_str()`.
4. Clear `#[allow(dead_code)]` on the two pure formatters.
5. JSON/human body shape unchanged aside from explicit as_str (same tokens).
6. Local gates and independent review pass.
