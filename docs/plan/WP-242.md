# WP-242 — Display for Effort

## Outcome

`Effort` implements `Display` via existing public `as_str`.

## Motivation

Route human formatters already use `effort.as_str()`. Adding `Display` matches
the domain token train so formatters can use `{}` consistently.

## Acceptance

1. `impl Display for Effort` delegates to `as_str`.
2. Unit test locks Display tokens.
3. Local gates and independent review pass; no CI isolation train.
