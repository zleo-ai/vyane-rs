# WP-340 — AttemptOutcome kind tokens + pure line

## Outcome

`AttemptOutcome` publishes snake_case kind-only `as_str` tokens (`ok` / `err`),
and CLI ships pure `format_attempt_outcome_line`.

## Motivation

Dispatch attempt results carried error kind, free-form message, and failover
flags with no closed top-level kind surface for diagnostics. After WP-339 this
was the remaining surveyed attempt-outcome enum without `as_str`.

## Acceptance

1. Every `AttemptOutcome` variant has a stable snake_case kind via `as_str`.
2. Tokens never embed error kinds, messages, or `failed_over`.
3. Unit tests lock both kinds with a secret message fixture.
4. Pure `format_attempt_outcome_line` is unit-tested.
5. Local gates and independent review pass.
