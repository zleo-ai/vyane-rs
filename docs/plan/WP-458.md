# WP-458 — Pure TakeoverApprovalStatus on continuity-execute consume/finish

## Outcome

CLI `goal continuity-execute` logs pure `format_takeover_approval_status_line`
after `consume_takeover_approval` (InFlight) and after
`finish_takeover_approval` (Done/Blocked), matching queue/decide settle via
`print_takeover_result`.

## Motivation

WP-457 covers admission pure status. Execute then consumes the approval to
InFlight and finishes to Done/Blocked; those closed statuses are printed
human/JSON but were not pure-logged (unlike queue/decide settle).

## Acceptance

1. Reuse pure `format_takeover_approval_status_line` (no new private table).
2. After consume, log pure line + `status = as_str` (InFlight path).
3. After finish settle, log pure line + `status = as_str` (Done/Blocked).
4. Unit tests lock InFlight / Done / Blocked pure tokens.
5. JSON/human settle bodies unchanged.
6. Local gates and independent review pass.
