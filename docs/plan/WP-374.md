# WP-374 — Pure executor/settlement lines on Process AgentRun settle

## Outcome

Process AgentRun final settle path logs pure `format_agent_executor_outcome_line`
and, when quiesced, pure `format_agent_execution_settlement_line`.

## Motivation

WP-343/345 published pure executor and execution-settlement lines. Process
AgentRun still returned those outcomes without pure kind messages on the final
settle path.

## Acceptance

1. Quiesced settle logs pure executor outcome line + pure execution settlement line.
2. Spool-remove failure (Unknown) logs pure executor outcome line.
3. Structured fields remain kind-only via `as_str`.
4. Both pure formatters drop `#[allow(dead_code)]`.
5. Local gates and independent review pass.
