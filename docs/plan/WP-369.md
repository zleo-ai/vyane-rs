# WP-369 — Wire pure GoalStoreError line on quarantine pause failure

## Outcome

Resident goal quarantine pause failures that are soft-handled log pure
`format_goal_store_error_kind_line` instead of a free-form English message.

## Motivation

WP-302/363 wired pure goal-store lines on acquisition. Quarantine persist still
used a free-form message body with only a structured kind field.

## Acceptance

1. Soft-handled quarantine pause Err logs pure `format_goal_store_error_kind_line` as message.
2. Structured `error` remains kind-only via `as_str`.
3. Local gates and independent review pass.
