# WP-360 — Pure diagnostics config/credential/profile status lines

## Outcome

CLI ships pure kind-only human lines for `ConfigCheckStatus`, `CredentialStatus`,
`ProfileCheckStatus`, `NativePermissionAxisStatus`, and `ConfigIssueCode`.

## Motivation

These diagnostics enums already publish snake_case `as_str` tokens used on
config-check surfaces, but lacked pure CLI formatters. After WP-359 this was
the remaining surveyed half-landed pure-line gap for diagnostics statuses.

## Acceptance

1. Pure formatters for all five enums use only domain `as_str`.
2. Unit tests lock one non-trivial token per formatter.
3. Local gates and independent review pass.
