# WP-440 — Pure legacy TaskState on detached task status print

## Outcome

CLI ships pure `format_legacy_task_state_line` and logs it when printing
legacy detached task status (status.json + displayed state).

## Motivation

Legacy detached `TaskState` already has `as_str`. The human status printer
embeds `displayed.as_str()` without a pure kind diagnostic (durable path uses
`vyane_task::TaskState` pure lines separately).

## Acceptance

1. Pure `format_legacy_task_state_line` uses `state.as_str()` + `terminal_safe`.
2. `print_task_status` logs pure line + `state = as_str`.
3. Unit tests lock representative tokens including synthetic died/stale.
4. Human multi-line legacy status body shape unchanged.
5. Local gates and independent review pass.
