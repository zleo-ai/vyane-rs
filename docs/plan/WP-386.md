# WP-386 — Wire pure TaskState lines on workflow cancel observation

## Outcome

Daemon workflow cancel logs pure `format_task_state_line` when the durable task
is already terminal or already cancelling.

## Motivation

WP-353 published pure task-state lines; WP-385 wired run-state on AgentRun
cancel observation. Workflow cancel observation still lacked pure task-state
messages.

## Acceptance

1. Terminal cancel observation logs pure task-state line + `state = as_str`.
2. Cancelling cancel observation logs pure task-state line + `state = as_str`.
3. `format_task_state_line` drops `#[allow(dead_code)]`.
4. Local gates and independent review pass.
