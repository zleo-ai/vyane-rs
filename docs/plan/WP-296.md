# WP-296 — Log preflight next-request validation kind

## Outcome

Native turn driver preflight that proves a worst-case tool result still fits
the next request logs `ToolChatValidationError::as_str` on failure (closing
the WP-295 residual).

## Motivation

WP-295 wired initial/loop request/response validation kinds. The pre-side-effect
`next_request_with_result(...).validate()` path still discarded the kind with
`map_err(|_| ())`.

## Acceptance

1. Preflight validation failure logs `error = as_str` (kind only).
2. Still returns `invalid_model_response` / no side effects before tools.
3. Local gates and independent review pass.
