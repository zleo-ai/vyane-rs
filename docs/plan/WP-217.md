# WP-217 — Pure cancel diagnostics and workflow observer step lines

## Outcome

Human cancel ownership/diagnostic lines and `CliWorkflowObserver` step event
lines go through pure helpers with terminal-safe free text.

## Motivation

Remaining operator diagnostics for cancel races and workflow step progress were
still ad-hoc `eprintln!` interpolations.

## Acceptance

1. Cancel ownership-changed and diagnostic paths use pure formatters.
2. Workflow observer started/succeeded/failed/skipped/cancelled use pure
   formatters (terminal-safe step ids/reasons/errors).
3. Unit tests drive the shipped formatters.
4. Local gates and independent review pass; no CI isolation train.
