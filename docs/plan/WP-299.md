# WP-299 — Pure AgentStoreError line + native authority map wire

## Outcome

CLI pure `format_agent_store_error_kind_line` prints `AgentStoreError` kinds.
`map_store_error` in native authority logs the kind when mapping store
failures to VyaneError.

## Motivation

WP-298 published tokens. Native authority still maps store errors without a
kind diagnostic on the shipped permit path.

## Acceptance

1. `format_agent_store_error_kind_line(e)` → `agent store: <as_str>`.
2. `map_store_error` logs `error = as_str` before mapping.
3. Unit tests lock multi-word tokens; gates + independent review pass.
