# WP-277 — Goal read / continuity runner error kind tokens

## Outcome

`GoalReadError`, `GoalContinuityRunnerError`, and
`GoalContinuityRunnerAuthorityError` publish snake_case `as_str` tokens.
CLI pure `format_goal_read_error_kind_line` prints the kind; REST
continuity-next logs the kind on closed GoalReadError failures.

## Motivation

Continuity read-only projection (P1/P2 seam) still maps GoalReadError only by
exhaustive match. Operators need a closed kind vocabulary for protocol and
daemon logs, parallel to AgentRun supervisor error tokens.

## Acceptance

1. `GoalReadError::as_str` covers all variants.
2. `GoalContinuityRunnerError::as_str` and
   `GoalContinuityRunnerAuthorityError::as_str` cover all variants.
3. `format_goal_read_error_kind_line(error)` → `goal read: <as_str>` via
   `terminal_safe`.
4. REST continuity-next logs the kind line for every closed `GoalReadError`
   (in addition to HTTP mapping).
5. Unit tests lock multi-word tokens; gates + independent review pass.
