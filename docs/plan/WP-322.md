# WP-322 — Pure ErrorKind line

## Outcome

CLI ships pure `format_error_kind_line_token` over kernel `ErrorKind::as_str`.

## Motivation

`ErrorKind` already has domain tokens used by kernel post-run logs (WP-318).
CLI pure lines still lacked a formatter for the closed failover taxonomy.

## Acceptance

1. Pure line renders `error kind: <kind>` from domain tokens.
2. Unit tests lock multi-word and short kinds.
3. Local gates and independent review pass.
