# WP-348 — Kind-only completion sink observation logs on recovery

## Outcome

Agent recovery logs closed `AgentCompletionSinkObservation` kind tokens after
completion sink inspect, without digests or publication keys.

## Motivation

WP-347 published sink observation kinds. Recovery still had no structured
operator signal for exact / absent / conflict / unavailable inspect results.

## Acceptance

1. After completion-sink inspect resolves, log `observation` as a kind token only.
2. Never log digests, publication keys, or free-form text in that structured log.
3. Local gates and independent review pass.
