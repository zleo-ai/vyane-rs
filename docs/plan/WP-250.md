# WP-250 — Domain tokens for quota closed enums

## Outcome

`QuotaStatus`, `QuotaUnit`, `QuotaConnectorErrorCode`, and `QuotaSnapshotStatus`
expose public `as_str` / `Display`.

## Motivation

These closed quota snapshot enums are already serde snake_case. Domain tokens
continue the diagnostic train after goal observation (WP-249) on the P3 quota
connector surface.

## Acceptance

1. All four enums have `as_str` + `Display`.
2. Unit tests lock multi-word tokens (`usd_micros`, `rate_limited`,
   `invalid_response`).
3. Local gates and independent review pass; no CI isolation train.
