# WP-303 — MessageStoreError kind tokens

## Outcome

`MessageStoreError` publishes snake_case kind-only `as_str` tokens so A2A /
message completion paths can report store failures without delivery ids or
payloads.

## Motivation

Agent and goal stores already have kind tokens (WP-298, WP-301). The message
store is the remaining owner-scoped SQLite surface with free-form Display errors
and no kind API.

## Acceptance

1. Every `MessageStoreError` variant has a stable snake_case kind token via `as_str`.
2. Tokens never embed delivery ids, operations, states, or IO/SQLite payloads.
3. Unit tests lock representative variants including payload-bearing ones.
4. Local gates and independent review pass.
