# WP-182 — CLI human `broadcast` table pure formatter + tests

## Outcome

Human broadcast result table goes through pure `format_broadcast_table` used by
`print_broadcast_table`. Unit tests drive the shipped formatter for success and
error rows.

## Motivation

WP-179–181 locked task/workflow human list paths. Broadcast still used only
untestable `println!`s for multi-target result projection.

## Acceptance

1. `print_broadcast_table` is a thin wrapper over `format_broadcast_table`.
2. Success rows show target, status name, duration ms, and first output line.
3. Error rows show `error` status, `-` duration, and error text.
4. Unit tests call the shipped formatter with real `BroadcastRow` / `RunRecord`.
5. Local gates and independent review pass; no CI isolation train.
