# WP-325 — PumpItemStatus kind tokens + degraded pump logs

## Outcome

`PumpItemStatus` publishes snake_case kind-only `as_str` tokens. The resident
broker supervisor logs degraded pump items with those kinds, and CLI ships a
pure `format_pump_item_status_line`.

## Motivation

Broker pump cycles already count degraded items but had no stable kind surface
for operators. Nested `ReplyEnqueued.message_id` must stay out of tokens and
logs.

## Acceptance

1. Every `PumpItemStatus` variant has a stable snake_case kind via `as_str`.
2. Tokens never embed message ids.
3. Unit tests lock all kinds including payload-bearing `ReplyEnqueued`.
4. Degraded pump items log `status = item.status.as_str()` (kind-only).
5. Pure `format_pump_item_status_line` is unit-tested.
6. Local gates and independent review pass.
