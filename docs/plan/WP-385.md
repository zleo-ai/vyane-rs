# WP-385 — Wire pure RunState lines on cancel observation

## Outcome

Daemon AgentRun cancel logs pure `format_run_state_line` when the durable run is
already terminal or already cancelling (idempotent observation paths).

## Motivation

WP-353 published pure run-state lines. Cancel's safe observation of terminal and
cancelling states still returned views without pure kind messages.

## Acceptance

1. Terminal cancel observation logs pure run-state line + structured `state = as_str`.
2. Cancelling cancel observation logs pure run-state line + structured `state = as_str`.
3. `format_run_state_line` drops `#[allow(dead_code)]`.
4. Local gates and independent review pass.
