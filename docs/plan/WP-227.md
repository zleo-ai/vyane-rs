# WP-227 — Pure invalid-JSON tool-arguments output (native turn driver)

## Outcome

When the native turn driver receives `ToolCallArguments::InvalidJson`, the
model-facing ERROR string comes from a pure helper shared with the rest of the
native tool ERROR surface (WP-205–207).

## Motivation

Prepare/execute tool ERROR strings were purified, but turn_driver still used a
private const for invalid JSON arguments — a parallel model-facing contract
without unit coverage.

## Acceptance

1. `invalid_json_tool_arguments_output()` pure helper exists (static string).
2. Turn driver InvalidJson branch uses that helper (no private const).
3. Unit test locks the shipped string contract.
4. Local gates and independent review pass; no CI isolation train.
