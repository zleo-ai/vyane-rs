# WP-392 — Wire pure MessageStoreError on A2A store open

## Outcome

Local A2A store open failures log pure `format_message_store_error_kind_line`
before returning the existing anyhow path context.

## Motivation

WP-311 published pure message-store error lines. A2A open still used only
path-bearing anyhow context without a kind-only pure diagnostic.

## Acceptance

1. `SqliteMessageStore::open` Err logs pure message-store line + `error = as_str`.
2. Existing path-bearing anyhow context is preserved for the returned error.
3. `format_message_store_error_kind_line` drops `#[allow(dead_code)]`.
4. Local gates and independent review pass.
