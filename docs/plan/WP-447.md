# WP-447 — Pure GoalSignalKind on REST continuity-next accepted signals

## Outcome

REST `GET /v1/goals/{id}/continuity-next` logs pure `format_goal_signal_kind_line`
for each projected allowlisted `accepted_signals` kind on success.

## Motivation

WP-408/WP-446 cover CLI continuity signal pure residual. The REST continuity-next
success path already materializes closed `GoalSignalKind` values on
`GoalNextActionView.accepted_signals` but did not pure-log them (error kinds
were covered by WP-277).

## Acceptance

1. Add pure `format_goal_signal_kind_line` over `GoalSignalKind::as_str`.
2. REST success path logs pure line + `kind = as_str` for each accepted signal.
3. Empty `accepted_signals` emits no extra signal pure logs.
4. Unit tests lock all three closed signal tokens.
5. JSON response body and status mapping unchanged.
6. Local gates and independent review pass.
