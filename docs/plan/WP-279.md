# WP-279 — Goal observation ingress/runner error kind tokens

## Outcome

`GoalObservationIngressError` and `GoalObservationRunnerError` publish
snake_case `as_str` tokens with unit tests locking multi-word kinds.

## Motivation

Observation ingress (WP-81) is a P1/P2 half-landed mutation port. Watcher
error codes already have tokens; ingress/runner construction failures still
only have Display prose.

## Acceptance

1. `GoalObservationIngressError::as_str` covers all variants.
2. `GoalObservationRunnerError::as_str` covers all variants
   (`invalid_configuration`, `duplicate_watcher`).
3. Unit tests lock multi-word tokens.
4. Local gates and independent review pass.
