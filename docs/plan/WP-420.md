# WP-420 — Pure Effort on native genparams freeze

## Outcome

CLI ships pure `format_effort_line` and logs it when freezing native generation
params that carry an explicit closed `Effort`.

## Motivation

`Effort` already has kind tokens. The native freeze path copies effort into
durable genparams without a pure kind diagnostic.

## Acceptance

1. Pure `format_effort_line` uses `effort.as_str()` + terminal_safe.
2. When `params_snapshot` freezes `Some(effort)`, log pure line + `effort = as_str`.
3. Unit test locks low/medium/high/xhigh tokens.
4. Snapshot mapping unchanged.
5. Local gates and independent review pass.
