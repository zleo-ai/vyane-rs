# WP-373 — Wire pure RunStatus line on Process AgentRun non-quiesced terminals

## Outcome

Process AgentRun host logs pure `format_run_status_line` (and lifecycle
observation) when a terminal run status arrives without quiescence, clearing
the silent `Unknown` path for Cancelled/Timeout/Error.

## Motivation

WP-357 published pure `RunStatus` lines. Process AgentRun still returned
`Unknown` for non-quiesced terminal statuses without a kind diagnostic message.

## Acceptance

1. Non-quiesced `Cancelled` / `Timeout` / `Error` logs pure run-status line + lifecycle line.
2. Structured fields remain kind-only (`status.as_str`, `lifecycle.as_str`).
3. `format_run_status_line` drops `#[allow(dead_code)]`.
4. Local gates and independent review pass.
