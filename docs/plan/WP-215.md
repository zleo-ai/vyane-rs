# WP-215 — Pure daemon absent/listening and goal-error lines

## Outcome

Human daemon listen/not-running/stale-removed messages and goal CLI error
prefix go through pure helpers:
`format_daemon_listening_line`, `format_daemon_not_running_line`,
`format_daemon_not_running_stale_line`, `format_goal_error_line`.

## Motivation

Remaining operator banners for absent daemon and goal errors were ad-hoc
string literals without pure unit coverage.

## Acceptance

1. Daemon run listen, status/stop not-running, stop stale-removed use pure
   formatters.
2. Goal CLI human error path uses `format_goal_error_line`.
3. Unit tests drive the shipped formatters.
4. Local gates and independent review pass; no CI isolation train.
