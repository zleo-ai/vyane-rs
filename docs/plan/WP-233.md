# WP-233 — Workflow summary step status uses domain token

## Outcome

Human `format_workflow_summary` step status column uses
`JournalStepStatus::as_str` (domain snake_case), not `Debug` + `to_lowercase`.

## Motivation

WP-232 published domain step tokens. The summary table still formatted status
via `format!("{:?}", step.status).to_lowercase()`, which drifts if multi-word
statuses appear and bypasses the domain API.

## Acceptance

1. Step status column uses `step.status.as_str()` (or Display).
2. Unit/coverage still green for workflow summary paths.
3. Local gates and independent review pass; no CI isolation train.
