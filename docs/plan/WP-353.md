# WP-353 — Pure lifecycle status lines (run/task/goal/workflow)

## Outcome

CLI ships pure kind-only human lines for `RunState`, `TaskState`, `GoalStatus`,
and `WorkflowRunStatus` closed tokens.

## Motivation

These lifecycle enums already publish snake_case `as_str` surfaces used on
domain and logging paths, but lacked pure CLI formatters for tests and operator
diagnostics. After WP-352 this was the remaining surveyed half-landed pure-line
gap for core lifecycle status enums.

## Acceptance

1. Pure `format_run_state_line` uses only `RunState::as_str`.
2. Pure `format_task_state_line` uses only `TaskState::as_str`.
3. Pure `format_goal_status_line` uses only `GoalStatus::as_str`.
4. Pure `format_workflow_run_status_line` uses only `WorkflowRunStatus::as_str`.
5. Unit tests lock one non-trivial token per formatter.
6. Local gates and independent review pass.
