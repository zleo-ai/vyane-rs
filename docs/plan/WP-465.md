# WP-465 — Pure ErrorKind on native failover-eligible continue

## Outcome

Native AgentRun multi-bound failover pure-logs `format_error_kind_line_token`
for the intermediate `ErrorKind` when a model/turn error is failover-eligible
and another bound remains (continue path).

## Motivation

WP-378/461 pure-log ErrorKind only when the attempt is the final settle
(`Ok(Err)` → quiesced failure or cancel Unknown). Intermediate failover
continues currently drop the materialised closed kind with no pure diagnostic,
even though the same host holds `error.kind` and the pure helper already
exists. Distinct lifecycle event from final settle (skip-to-next-bound vs
terminal mapping).

## Acceptance

1. Reuse pure `format_error_kind_line_token` (no new formatter).
2. On failover-eligible `Ok(Err(error))` when `index + 1 < bounds.len()`,
   pure-log error kind + `error = as_str` before `continue`.
3. Final settle paths (WP-378/461/464) and settlement codes unchanged.
4. Unit tests keep locking closed `error kind:` tokens.
5. Local gates and independent review pass.
