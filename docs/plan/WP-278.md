# WP-278 — Continuity runner error kind pure lines + reader-open wire

## Outcome

CLI pure formatters print `GoalContinuityRunnerError` /
`GoalContinuityRunnerAuthorityError` kind tokens. Service
`goal_continuity_runner` logs `GoalReadError::as_str` when opening the
reader fails before mapping to `Unavailable`.

## Motivation

WP-277 published continuity runner error tokens without a human pure line or
shipped diagnostic wire. Reader open is the only production map that collapses
GoalReadError into runner Unavailable — operators need the underlying kind.

## Acceptance

1. `format_goal_continuity_runner_error_kind_line(e)` →
   `continuity runner: <as_str>`.
2. `format_goal_continuity_authority_error_kind_line(e)` →
   `continuity authority: <as_str>`.
3. `VyaneService::goal_continuity_runner` logs `goal_read = error.as_str()`
   when `goal_reader` fails (before mapping to Unavailable).
4. Unit tests lock multi-word tokens; gates + independent review pass.
