# WP-294 — EditError kind tokens

## Outcome

`EditError` publishes snake_case kind-only `as_str` tokens (counts/limits stay
out of the token).

## Motivation

Bounded text-edit is a P1 trusted filesystem tool. Structured edit failures
should surface closed kinds for operators and tests without numeric payloads.

## Acceptance

1. `EditError::as_str` covers all variants kind-only
   (`no_match`, `not_unique`, `ambiguous`, `empty_old_string_on_non_empty_content`,
   `no_op_edit`, `output_too_large`, `too_many_matches`).
2. Unit tests lock multi-word tokens.
3. Local gates and independent review pass.
