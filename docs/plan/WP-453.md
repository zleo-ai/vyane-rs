# WP-453 — Pure TakeoverRunStatus on continuity-queue upstream evidence

## Outcome

CLI `goal continuity-queue` logs pure `format_takeover_run_status_line` when
upstream predecessor evidence carries a closed `TakeoverRunStatus`.

## Motivation

WP-395 covers execute-finish run status. Continuity-queue freezes optional
upstream run status from predecessor approval evidence without pure-logging
that closed kind when present.

## Acceptance

1. Reuse pure `format_takeover_run_status_line` (no new private table).
2. `continuity_queue` logs pure line + `status = as_str` when
   `upstream_run_status` is `Some`.
3. Absent upstream evidence emits no upstream-run pure log.
4. Existing pure step status (WP-452) and sandbox (WP-410) logs remain.
5. JSON/human bodies unchanged.
6. Local gates and independent review pass.
