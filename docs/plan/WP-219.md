# WP-219 — Pure durable cancel refuse / cleanup residual

## Outcome

Durable detached cancel's remaining ad-hoc human diagnostics — process-identity
unavailable refuse and terminal cleanup-failed — go through pure formatters.

## Motivation

WP-218 purified the legacy cancel identity path. The durable cancel path still
interpolates refuse-control and cleanup-failed lines in
`refuse_unverifiable_cancel` / `cleanup_observed_terminal`.

## Acceptance

1. `cleanup_observed_terminal` uses `format_task_already_cleanup_failed_line`.
2. `refuse_unverifiable_cancel` uses a pure process-identity-unavailable line
   helper with terminal-safe task id.
3. Unit tests cover the new (or reused) helpers with exact contracts.
4. Local gates and independent review pass; no CI isolation train.
