# WP-375 — Pure executor/settlement lines on native AgentRun settle

## Outcome

Native AgentRun settle paths (quiesced failure helper and completion-staged
success / staging Unknown) log pure executor and execution-settlement lines,
mirroring WP-374 for Process AgentRun.

## Motivation

WP-374 wired pure settle diagnostics on Process AgentRun. Native AgentRun still
returned `Quiesced` / `Unknown` without pure kind messages on the same settle
surfaces.

## Acceptance

1. `quiesced_failure` logs pure executor (+ settlement when quiesced).
2. Completion staging success logs pure executor + `completion_staged` settlement.
3. Completion staging Unknown logs pure executor `unknown`.
4. Structured fields remain kind-only via `as_str`.
5. Local gates and independent review pass.
