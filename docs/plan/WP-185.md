# WP-185 — CLI human legacy session line pure formatter + tests

## Outcome

Human legacy session list lines go through pure `format_legacy_session_line`
used by `print_legacy_session_line`. Unit tests drive the shipped formatter with
real `SessionRecord` values.

## Motivation

Companion to WP-184 for the legacy `sessions` list path still projecting
session id, target, run_count, and updated_at via untestable `println!`s.

## Acceptance

1. `print_legacy_session_line` wraps `format_legacy_session_line`.
2. Line includes session_id, target Display, run_count, updated_at RFC3339.
3. Unit tests call the shipped formatter with real `SessionRecord`.
4. Local gates and independent review pass; no CI isolation train.
