# WP-441 — Pure RouteTier/RouteEffort on route result print

## Outcome

CLI ships pure `format_route_tier_line` and `format_route_effort_line`, and logs
them when printing `vyane route` human results.

## Motivation

`RouteTier` and `RouteEffort` already have kind tokens. The route printer
embeds them in a multi-line body without pure kind diagnostics (distinct from
core `Effort` pure lines used on native freeze).

## Acceptance

1. Pure tier/effort lines use `as_str()` + `terminal_safe`.
2. `print_route_result` logs both pure lines + structured as_str fields.
3. Unit tests lock representative tokens.
4. Human multi-line route result shape unchanged.
5. Local gates and independent review pass.
