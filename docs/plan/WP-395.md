# WP-395 — Pure TakeoverRunStatus on continuity execute finish

## Outcome

Goal continuity execute logs pure `format_takeover_run_status_line` when a
dispatch finishes (success or error status).

## Motivation

WP-358 published pure takeover-run status lines. Continuity execute already
mapped dispatch outcomes to `TakeoverRunStatus` without a pure kind message.

## Acceptance

1. Dispatch Ok logs pure takeover-run status for the mapped run status.
2. Dispatch Err logs pure `takeover run: error`.
3. Structured `status` remains kind-only via `as_str`.
4. `format_takeover_run_status_line` drops `#[allow(dead_code)]`.
5. Local gates and independent review pass.
