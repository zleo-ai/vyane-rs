# WP-212 — Pure generic error / worker-error CLI prefix lines

## Outcome

Human `error:` and `worker error:` stderr prefixes go through pure
`format_error_line` / `format_worker_error_line` for CLI command and main
error paths that previously used ad-hoc `eprintln!`.

## Motivation

After WP-210/211 purified config-error prefixes, generic runtime and worker
errors remained unshared string templates.

## Acceptance

1. Remaining `error:` / `worker error:` human paths in command.rs and main.rs
   use the pure helpers.
2. Prefix shapes match the prior contract.
3. Unit tests drive the shipped helpers.
4. Local gates and independent review pass; no CI isolation train.
