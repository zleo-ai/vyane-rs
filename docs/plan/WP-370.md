# WP-370 — Wire pure GoalStoreError lines on resident pursuit error paths

## Outcome

Resident goal config validation, pursuer construction, and pursuit-stop error
logs use pure `format_goal_store_error_kind_line` as the message body.

## Motivation

WP-363/369 wired pure goal-store lines on acquisition and quarantine. Other
resident pursuit error paths still used free-form English messages with only a
structured kind field.

## Acceptance

1. Pursuit config validate Err logs pure goal-store line + `error = as_str`.
2. Pursuer construction Err logs pure goal-store line + `error = as_str`.
3. Pursuit stop Err logs pure goal-store line + `error = as_str`.
4. Local gates and independent review pass.
