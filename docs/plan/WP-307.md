# WP-307 — EventLogError kind tokens

## Outcome

`EventLogError` publishes snake_case kind-only `as_str` tokens so ledger and
broker projection paths can report failures without free-form IO/JSON payloads.

## Motivation

BrokerError already maps `Event(_)` to a coarse kind (WP-306). The ledger error
surface itself still lacks kind tokens for operator diagnostics.

## Acceptance

1. Every `EventLogError` variant has a stable snake_case kind token via `as_str`.
2. Tokens never embed messages, lock modes, schema numbers, or IO/JSON payloads.
3. Unit tests lock representative variants including payload-bearing ones.
4. Local gates and independent review pass.
