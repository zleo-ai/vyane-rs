# WP-427 — Pure SessionNativeState on session list/inspect

## Outcome

CLI ships pure `format_session_native_state_line` and logs it when printing
owner-scoped `SessionView` lines (list/inspect human path).

## Motivation

`SessionNativeState` already has closed snake_case tokens. The human session
view embeds `native_state.as_str()` in a multi-field line but does not emit a
standalone pure kind diagnostic for operators/tracing.

## Acceptance

1. Pure `format_session_native_state_line` uses `state.as_str()` + `terminal_safe`.
2. `print_session_view_line` logs pure line + `native_session = as_str`.
3. Unit tests lock absent / legacy_unbound / bound / unknown tokens.
4. Human multi-field session line shape unchanged.
5. Local gates and independent review pass.
