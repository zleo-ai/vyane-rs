# WP-350 — Kind-only agent recovery item status logs + pure line

## Outcome

Daemon agent recovery logs closed `AgentRecoveryItemStatus` kind tokens after
each recovered ticket, and CLI ships pure `format_agent_recovery_item_status_line`.

## Motivation

`AgentRecoveryItemStatus` already had `as_str` from the earlier recovery train,
but per-item recovery settlement still lacked a structured operator signal and
a pure human line.

## Acceptance

1. After each `recover_one` result, log `status` as a kind token only.
2. Never log run ids, controller refs, or free-form text in that structured log.
3. Pure `format_agent_recovery_item_status_line` is unit-tested.
4. Local gates and independent review pass.
