# WP-297 — Native turn limit and host/register error kind tokens

## Outcome

`NativeTurnLimitError`, `NativeReadHostError`, `NativeCommandHostError`, and
`RegisterCommandToolError` publish snake_case kind-only `as_str` tokens.

## Motivation

Turn-budget construction and Linux host/register admission are P1 native
setup paths. Closed kinds enable diagnostics without path/policy payloads.

## Acceptance

1. `NativeTurnLimitError::as_str` covers `zero` / `above_hard_maximum`.
2. Host errors expose `unsupported`.
3. `RegisterCommandToolError::as_str` is kind-only
   (`command_policy`, `network_policy`, `registry`).
4. Unit tests lock multi-word tokens.
5. Local gates and independent review pass.
