# WP-121 — multi-thread authorized web-search MockServer fixtures

## Outcome

Run authorized OpenAI Responses web-search fixtures in
`authorized_web_search` on a two-worker Tokio runtime so MockServer-backed
cancel, retry, and bounded-response paths stay independently schedulable under
suite load.

Production web-search protocol behavior does not change.

## Motivation

WP-111 multi-threaded native AgentRun web-search acceptances, and WP-117
multi-threaded authorized OpenAI Chat cancel fixtures. The library-level
authorized web-search suite still used the default current-thread runtime for
all four MockServer cases.

## Acceptance

1. All four authorized web-search fixtures use two Tokio workers.
2. Existing assertions remain unchanged.
3. No production code changes.
4. Local targeted runs, gates, review, PR CI, and exact merged-main CI pass.
