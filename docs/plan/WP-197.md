# WP-197 — Goal get event rows use domain GoalEventKind Display

## Outcome

Human `vyane goal get` event rows go through pure `format_goal_event_line`.
The private CLI `event_kind_text` match table is removed; kind tokens come only
from public domain `GoalEventKind::as_str` / Display (WP-196).

## Motivation

WP-196 published domain kind tokens for progress lines, but goal detail still
duplicated the same snake_case table in the CLI. One source of truth prevents
kind drift.

## Acceptance

1. Human goal get event rows use `format_goal_event_line` (JSON unchanged).
2. Line is tab-separated: revision, RFC3339 timestamp, kind snake_case Display.
3. Private `event_kind_text` is gone; no CLI-local kind match table remains.
4. Unit test drives the shipped formatter with a real `GoalEvent` and asserts
   domain `as_str` alignment.
5. Local gates and independent review pass; no CI isolation train.
