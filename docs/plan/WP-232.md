# WP-232 — Domain WorkflowRunStatus / JournalStepStatus tokens

## Outcome

`WorkflowRunStatus` and `JournalStepStatus` expose public `as_str` / `Display`.
CLI `workflow_status_name` uses the domain token (no private match table).

## Motivation

CLI human workflow summaries duplicate snake_case status names in
`workflow_status_name`. Domain ownership prevents drift (same pattern as
WP-197 goal event kinds).

## Acceptance

1. `WorkflowRunStatus` and `JournalStepStatus` have public `as_str` + `Display`.
2. `workflow_status_name` returns `status.as_str()` only.
3. Unit tests lock domain tokens; existing CLI workflow summary tests still pass.
4. Local gates and independent review pass; no CI isolation train.
