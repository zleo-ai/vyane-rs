# WP-426 — Pure Sandbox on process AgentRun submit freeze

## Outcome

CLI logs pure `format_sandbox_line` when freezing a process AgentRun submission
with a closed `Sandbox` (reusing the WP-411 pure helper).

## Motivation

`Sandbox` already has kind tokens and a pure CLI line used on goal pursue.
Process AgentRun submit maps spool sandbox into `Sandbox` without emitting that
pure diagnostic.

## Acceptance

1. Reuse pure `format_sandbox_line` (`sandbox.as_str()` + `terminal_safe`).
2. When process AgentRun submit freezes sandbox, log pure line +
   `sandbox = as_str`.
3. Unit tests already lock read-only/write/full tokens (no regression).
4. Submit mapping unchanged.
5. Local gates and independent review pass.
