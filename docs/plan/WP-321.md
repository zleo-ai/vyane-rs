# WP-321 — Pure OnError policy line

## Outcome

CLI ships pure `format_on_error_policy_line` over `OnError::as_str` tokens.

## Motivation

WP-317 published `OnError` kinds. Operator pure lines still lacked a formatter
for the step failure policy surface.

## Acceptance

1. Pure line renders `on_error: <kind>` for `abort` and `continue`.
2. Unit tests lock both policies.
3. Local gates and independent review pass.
