# WP-266 — Pure human line for native tool invocation status

## Outcome

CLI pure formatter `format_tool_invocation_status_line` prints the closed
`ToolInvocationStatus` token (including `approval_required`) without Debug.

## Motivation

Stream and operator surfaces still need a pure, terminal-safe line for the
native ask/deny/error vocabulary published in WP-261. This half-lands the
human formatter on the same tokens the turn driver settles.

## Acceptance

1. `format_tool_invocation_status_line(status)` returns
   `tool status: <token>` using `status.as_str()` + `terminal_safe`.
2. Unit test locks multi-word tokens and strips control characters.
3. Local gates and independent review pass; no CI isolation train.
