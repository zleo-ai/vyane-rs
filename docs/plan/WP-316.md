# WP-316 — Kind-only harness lifecycle report log

## Outcome

Harness process-group stop reporting failures log a fixed `lifecycle_report`
kind instead of free-form `error = %error` Display.

## Motivation

CLI/daemon `%error` kind train is largely closed (WP-309…WP-315). The last
workspace `error = %error` site was harness lifecycle stop reporting, which
could embed IO Display strings.

## Acceptance

1. `report_stopped` failure logs `error = "lifecycle_report"` (no Display).
2. No `error = %error` remains under `crates/` for structured tracing fields.
3. Local gates and independent review pass.
