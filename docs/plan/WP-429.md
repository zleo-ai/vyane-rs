# WP-429 — Pure ErrorKind on session control failures

## Outcome

CLI logs pure `format_error_kind_line_token` when session control commands fail
with a closed kernel `ErrorKind`.

## Motivation

`ErrorKind` already has pure tokens used on native AgentRun failure mapping.
Session list/inspect/reset-native failure paths map kinds to operator views
without a pure kind diagnostic.

## Acceptance

1. Reuse pure `format_error_kind_line_token` (`kind.as_str()` + `terminal_safe`).
2. `print_session_control_error` logs pure line + `error_kind = as_str`.
3. Operator session-control error view / exit codes unchanged.
4. Existing ErrorKind unit asserts remain green.
5. Local gates and independent review pass.
