# WP-235 — Domain NativePermissionAxisStatus tokens + CLI wire

## Outcome

`NativePermissionAxisStatus` exposes public `as_str` / `Display`. CLI
`native_axis_name` uses domain tokens only (no private match table).

## Motivation

Permission-check human lines (WP-193) still map axis statuses through a CLI
private match. Domain ownership matches the WP-197/232 token train.

## Acceptance

1. Domain `as_str` + `Display` for all three axis statuses.
2. CLI `native_axis_name` returns `status.as_str()`.
3. Unit tests lock domain tokens; existing permission-check human tests pass.
4. Local gates and independent review pass; no CI isolation train.
