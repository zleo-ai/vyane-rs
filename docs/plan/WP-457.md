# WP-457 — Pure TakeoverApprovalStatus on continuity-execute admission

## Outcome

CLI `goal continuity-execute` logs pure `format_takeover_approval_status_line`
for the loaded approval status before admission check.

## Motivation

WP-393 covers decide/queue settle pure approval status. Continuity-execute
already loads a closed `TakeoverApprovalStatus` and rejects non-approved rows
without pure-logging that kind at admission.

## Acceptance

1. Reuse pure `format_takeover_approval_status_line` (no new private table).
2. `continuity_execute` logs pure line + `status = as_str` after load, before
   the Approved admission check.
3. Non-approved rows still fail closed after the pure log.
4. Execute behavior and prompt bodies unchanged.
5. Local gates and independent review pass.
