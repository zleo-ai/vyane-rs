# WP-209 — Pure detached-task status error lines

## Outcome

Human stderr for missing detached runs, missing output artifacts, and non-local
dispatch ids go through pure `format_no_such_detached_run_line`,
`format_no_output_recorded_line`, and `format_not_local_detached_line`
(terminal-safe ids).

## Motivation

Task status/output/cancel diagnostics still interpolated run ids into ad-hoc
`eprintln!` without escape coverage or pure unit tests.

## Acceptance

1. Not-found, no-output, and not-local detached human paths use the pure
   formatters.
2. Free-text ids are terminal-safe; message prefixes match the prior contract.
3. Unit tests drive the shipped formatters.
4. Local gates and independent review pass; no CI isolation train.
