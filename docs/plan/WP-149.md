# WP-149 — isolate resident native unit failover fixture in CI

## Outcome

Run `native_agent::tests::resident_native_run_fails_over_before_tool_activity`
in a fresh CI process for normal and coverage jobs.

Production native failover behavior does not change.

## Motivation

This multi_thread multi-mock resident native unit fixture drives concurrent
Wiremock targets during failover. Neighboring multi_thread native AgentRun
fixtures already required process isolation under suite/GHA load.

## Acceptance

1. Normal and coverage jobs skip the fixture in the serialized CLI suite.
2. Both jobs re-run it alone via `--exact` in a fresh process.
3. No production code or assertion changes.
4. Local gates, review, PR CI, and exact merged-main CI pass.
