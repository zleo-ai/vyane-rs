# WP-311 — Task/Message store kind lines + workflow lease logs

## Outcome

CLI ships pure `format_task_store_error_kind_line` and
`format_message_store_error_kind_line`. Resident workflow lease renewal and
metadata completion retries log `TaskStoreError` kinds instead of Display.

## Motivation

WP-303/WP-304 published store kind tokens. Daemon workflow still logged free-form
anyhow Display on lease renewal and completion retry paths that wrap the task
store.

## Acceptance

1. Pure lines render `task store: <kind>` and `message store: <kind>`.
2. Unit tests lock payload-bearing variants without embedding secrets.
3. Workflow lease renewal and metadata completion retry logs use TaskStoreError
   kinds (or `internal` when not a store error).
4. Local gates and independent review pass.
