# WP-96 — settle forced daemon termination before restart tests

## 目标

消除 daemon restart 接受测试中的测试侧竞态：发送 `SIGKILL` 后必须确认旧
daemon 已从内核进程表消失，才能启动替代 daemon。

本包不改变生产启动、存活判断或认证健康检查语义。

## 决策模型

- 测试辅助函数仍向记录的精确 daemon PID 发送 `SIGKILL`。
- `kill()` 在返回前以 `kill(pid, 0)` 语义等待 `ESRCH`，最长 10 秒。
- `EPERM` 和成功探测都视为进程仍存在；不能把不可发信号误报为已退出。
- 超时明确令测试失败，不用固定 sleep 猜测退出时序。

## 验收门

1. daemon restart 接受测试在普通与 LLVM coverage 构建下通过。
2. 全仓 format、Clippy、test 与 parity 通过。
3. 独立评审与云端 CI 验证精确提交。
